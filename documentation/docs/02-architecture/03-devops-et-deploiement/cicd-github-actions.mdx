## 🛠️ 2. Workflow GitHub Actions Typique

Exemple de structure d'un fichier `.github/workflows/ci.yml` :

```yaml
name: CI & Tests Automatisés

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  qualite:
    name: Lint & Typage TypeScript
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
        with:
          version: 9
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: "pnpm"
      - run: pnpm install --frozen-lockfile
      - run: pnpm lint
      - run: pnpm typecheck

  tests-unitaires:
    name: Tests Unitaires & Couverture
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: "pnpm"
      - run: pnpm install --frozen-lockfile
      - run: pnpm test:coverage

  tests-e2e:
    name: Tests de Bout en Bout Playwright
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: pnpm install --frozen-lockfile
      - run: npx playwright install --with-deps chromium
      - run: pnpm test:e2e
```

## 🛡️ 3. Politiques de Sécurité CI

- **Analyse des dépendances :** Dependabot et Socket.dev analysent en continu les failles CVE et les comportements suspects de paquets npm/Python.
- **Scan de vulnérabilités d'images :** Trivy inspecte les images Docker générées avant publication sur le registre de conteneurs.
