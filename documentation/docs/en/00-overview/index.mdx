# 🌐 The Universal Connected Data Standard

**Slasher** standardizes how rich text documents interact with verified remote public records, legal databases, corporate registers, and AI knowledge bases.

```mermaid
flowchart LR
    Slash["⌨️ User types /slash command"] --> Popover["🔍 Accessible Floating Popover"]
    Popover --> SDK["🛠️ Slasher Provider SDK (< 5 kB)"]
    SDK --> Proxy["🛡️ Defensive Backend Proxy (Anti-SSRF)"]
    Proxy --> Block["🧩 3-Format Switchable SlasherBlock"]
```
