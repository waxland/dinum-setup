# 🎨 Custom Styling & Theme Integration

Slasher blocks adapt automatically to your application's design system and theme mode (Light / Dark).

---

## 🌙 Dark Mode Support
Styles use contextual CSS custom properties for background, text colors, and borders, guaranteeing high contrast (minimum 4.5:1 ratio) in both light and dark themes.

---

## 🎨 Design Tokens & Custom Borders
Institutional border colors can be customized per entity via the `borderColor` property:
- 🇫🇷 Marianne Blue : `#000091`
- 🇪🇸 Spain Crimson : `#AA151B`
- 🇳🇱 Netherlands Orange : `#FF6600`
- 🇩🇪 Germany Gold/Black : `#000000`
- 🇪🇺 European Blue : `#003399`
