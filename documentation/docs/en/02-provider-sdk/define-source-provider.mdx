# 🛠️ `defineSourceProvider()` Helper

The `defineSourceProvider()` helper validates required properties at runtime and returns a deeply frozen `ExternalSourceProviderDefinition` object (`Object.freeze()`).

---

## 📋 Schema Definition Contract

```typescript
import { defineSourceProvider } from "@slasher/sdk";

export const myProvider = defineSourceProvider({
  name: "My Custom Source",
  slashCommand: "mysource",
  slashAliases: ["ms", "custom"],
  icon: "🚀",
  description: "Search and insert custom records",
  suggest: async (query, limit = 5) => {
    // Return autocomplete suggestions
    return [];
  },
  search: async (query, limit = 10) => {
    // Return full entity details
    return [];
  },
});
```
