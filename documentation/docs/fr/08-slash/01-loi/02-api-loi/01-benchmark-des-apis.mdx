---

## 📊 Matrice Comparative des 3 Sources

| Critère | 1. API PISTE / DILA (Légifrance) | 2. API Albert (IA Souveraine DINUM) | 3. Judilibre (Cour de Cassation) |
| :--- | :--- | :--- | :--- |
| **Périmètre** | Codes, lois, décrets, arrêtés, JORF, conventions | RAG juridique & synthèse multibase | Jurisprudence judiciaire |
| **Type de Recherche** | Exacte & Mots-clés (`/suggest`, `/search`) | Sémantique & Langage naturel | Filtres de décisions & arrêts |
| **Opposabilité** | Maximale (Référentiel légal de l'État) | Synthèse assistée avec citation | Décisions de justice ouvertes |
| **Temps de Réponse** | ~80 à 250 ms | ~600 à 1 200 ms | ~150 ms |
| **Accès & Clés** | Compte PISTE (OAuth2 Client Credentials) | Clé API Albert DINUM | API ouverte / data.gouv.fr |
| **Format Données** | JSON brut structuré DILA | Texte synthétisé + citations | JSON normalisé ECLI |

## 🎯 Recommandation pour La Suite Docs

1. **Socle Primaire : API PISTE / DILA**  
   Utilisé pour 90% des cas d'usage de la commande `/loi` (recherche rapide par numéro d'article ou mot-clé dans les codes).
2. **Module Optionnel : API Albert**  
   Activé en complément pour la rédaction assistée via la commande `/ai` ou pour suggérer des articles de loi pertinents à partir d'un paragraphe rédigé en langage naturel.
