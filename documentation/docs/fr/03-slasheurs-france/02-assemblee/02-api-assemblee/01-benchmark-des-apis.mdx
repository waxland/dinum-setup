---

## 📊 Matrice Comparative des Sources Parlementaires

| Critère | 1. API `claire.vite` | 2. `Tricoteuse` (Regards Citoyens) | 3. Open Data Direct (data.assemblee-nationale.fr) |
| :--- | :--- | :--- | :--- |
| **Type de Solution** | API REST JSON normalisée | Indexeur & Parser Open Source | Dumps XML / JSON bruts |
| **Temps de Réponse** | ~40 à 100 ms | Dépend de la base locale | Traitement batch lourd |
| **Fraîcheur des Données** | Temps réel (Polling 30s) | Temps réel via webhook/sync | Mises à jour quotidiennes/horaires |
| **Souveraineté & Auto-hébergement** | Service cloud / API externe | **100% Auto-hébergeable en local** | Source institutionnelle première |
| **Recherche par Numéro** | Optimisée (`/amendements?num=142`) | Requête SQL / Elastic locale | Parsing de zip complet requis |
| **Licence** | Ouverte | Libre (AGPLv3 / MIT) | Licence Ouverte v2.0 |

## 🎯 Recommandation d'Intégration

1. **Phase 1 (Immédiate) : Connecteur `claire.vite`**  
   Permet une mise en service instantanée avec des temps de réponse ultra-rapides (< 100 ms) pour la recherche d'amendements et de dossiers.
2. **Phase 2 (Souveraineté renforcée) : Connecteur `Tricoteuse`**  
   L'association *Regards Citoyens* maintient le moteur `tricoteuse-assemblee` qui parse l'intégralité des flux parlementaires. Docs permet de basculer sur une instance locale de Tricoteuse via `TRICOTEUSE_API_URL`.
