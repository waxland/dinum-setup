---

## 🎨 Rendu Visuel des 3 Formats DSFR

L'agent public peut basculer à tout moment entre les 3 formats :

1. 📢 **Format Callout (Encadré DSFR)** : Idéal pour les visas des arrêtés ou les citations in extenso.
2. 🗂️ **Format Carte (Card DSFR)** : Synthèse avec grille Code / Date d'effet / Identifiant.
3. 🔗 **Format Lien (Inline Badge)** : Mention compacte cliquable dans la phrase avec popover au survol.

### Variables à Configurer

```dotenv
# .env.local ou common.local
PISTE_CLIENT_ID=votre_client_id_piste
PISTE_CLIENT_SECRET=votre_client_secret_piste
PISTE_API_BASE_URL=https://api.piste.gouv.fr/dila/legifrance/lf-engine-app
PISTE_MOCK_ENABLED=false
```
