Les équipes de conception et de développement de **La Suite numérique** échangent quotidiennement de manière ouverte via le réseau souverain et décentralisé **Matrix**.

🔗 **Réseaux & Échanges :** [Protocole Matrix](https://matrix.org/) • [Client Element Web/Desktop](https://element.io/) • [Code de conduite des contributeurs](https://github.com/suitenumerique/.github/blob/main/CODE_OF_CONDUCT.md)

## 👥 Salons Matrix Officiels

Vous pouvez rejoindre librement les salons de discussion pour poser vos questions, remonter des anomalies ou échanger avec les mainteneurs :

| Thématique          | Salon Matrix                    | Lien direct                                                                      |
| ------------------- | ------------------------------- | -------------------------------------------------------------------------------- |
| **📝 Docs**         | `#docs-official:matrix.org`     | [Rejoindre le salon Docs](https://matrix.to/#/#docs-official:matrix.org)         |
| **📹 Meet / Visio** | `#meet-official:matrix.org`     | [Rejoindre le salon Meet](https://matrix.to/#/#meet-official:matrix.org)         |
| **📊 Projects**     | `#projects-official:matrix.org` | [Rejoindre le salon Projects](https://matrix.to/#/#projects-official:matrix.org) |
