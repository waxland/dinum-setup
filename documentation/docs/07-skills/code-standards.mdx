## 🛡️ Règle 1 : Zéro `any` et Zéro Cast de Type Abusif

### ❌ Mauvaises pratiques (Interdites)
```typescript
// ❌ INTERDIT : Utilisation de any
const handleSelect = (item: any) => { ... };
const editor: any = useCreateBlockNote(...);

// ❌ INTERDIT : Forçage de type avec "as any" ou "as unknown as Type"
(editor as any).insertBlocks([...]);
const props = block.props as unknown as SourceEntityProps;
```

### ✅ Bonnes pratiques (Exigées)
```typescript
// ✅ RECOMMANDÉ : Définir des interfaces strictes et utiliser les types du SDK
import { BlockConfig, BlockNoDefaults, BlockNoteEditor } from '@blocknote/core';

export type CreateSourceBlockConfig = BlockConfig<
  'sourceBlock',
  {
    entityType: { default: 'law' };
    displayMode: { default: 'callout' };
    sourceId: { default: '' };
    title: { default: '' };
  },
  'none'
>;

interface SourceComponentProps {
  block: BlockNoDefaults<Record<'sourceBlock', CreateSourceBlockConfig>, InlineContentSchema, StyleSchema>;
  editor: BlockNoteEditor<Record<'sourceBlock', CreateSourceBlockConfig>, InlineContentSchema, StyleSchema>;
}
```

## 🎨 Règle 2 : Zéro Tailwind CSS — Cunningham & DSFR Exclusifs

Dans les applications de La Suite (comme Docs / Impress), **Tailwind CSS n'est pas utilisé**. Tout le styling repose sur :

1. **Cunningham (`@openfun/cunningham-tokens`) :**
   - Variables CSS : `var(--c--globals--colors--brand-primary)`, `var(--c--globals--spacings--md)`.
   - Conteneur polymorphique universel : `<Box $direction="row" $align="center" $gap="sm">`.
   - Composants atomiques : `<Card>`, `<Text>`, `<Title>`, `<BoxButton>`.
2. **Design System de l'État (DSFR) :**
   - Classes officielles : `fr-callout`, `fr-card`, `fr-badge`, `fr-btn`.
   - Composants React officiels : `@codegouvfr/react-dsfr`.

### ❌ Mauvaises pratiques (Interdites)
```tsx
// ❌ INTERDIT : Classes utilitaires Tailwind arbitraires
<div className="flex items-center gap-2 p-4 bg-white dark:bg-gray-900 rounded-xl shadow-md">
```

### ✅ Bonnes pratiques (Exigées)
```tsx
// ✅ RECOMMANDÉ (Dans Impress) : Primitives Cunningham
import { Box, Card, Text } from '@/components';

<Box
  $direction="row"
  $align="center"
  $gap="xs"
  $padding="md"
  $background="var(--c--contextuals--background--surface--primary)"
  $border="1px solid var(--c--contextuals--border--surface--primary)"
  $radius="4px"
>
  <Text $size="sm" $weight="bold">Contenu certifié</Text>
</Box>
```

## 🚫 Règle 3 : Proscription de `@mantine/core` dans l'Interface Utilisateur

- `@mantine/core` et `@blocknote/mantine` sont des dépendances techniques internes requises par le canvas d'édition de BlockNote.
- **Aucun composant de l'application (bouton, menu, popover, modale, champ de saisie) ne doit importer `@mantine/core`.**
- Pour les interfaces interactives flottantes, utiliser :
  - **`DropButton` & `react-aria-components`** pour les menus déroulants et popovers accessibles.
  - **`<QuickSearch>` (`cmdk`)** pour les palettes d'autocomplétion et de recherche.

---

## 🧩 Règle 4 : Architecture des Custom Blocks BlockNote

Tout bloc d'extension documentaire (ex: `SourceBlock`, `CalloutBlock`) doit respecter le pattern officiel :

1. **Factory Function :** Le bloc est instancié par une fonction factory sans arguments (ex: `export const SourceBlock = () => createReactBlockSpec(...)`).
2. **PropSchema Explicite :** Chaque propriété possède une valeur par défaut typée sans valeur `null` orpheline.
3. **Double État :**
   - *État Recherche :* Popover inline déclenché sous le curseur avec focus immédiat et navigation au clavier (`↑`, `↓`, `Entrée`, `Échap`).
   - *État Rendu :* 3 formats DSFR interchangeables au survol (**Encadré Marianne**, **Carte 3-colonnes**, **Pastille Lien**).

---

## ♿ Règle 5 : Accessibilité Universelle RGAA v4.1 (Niveau AA)

- **Clavier :** 100% utilisable sans souris. La touche `Échap` doit annuler sans laisser de bloc corrompu ni de bloc vide.
- **Attributs ARIA :** Tout champ de recherche avec autocomplétion doit porter `role="combobox"`, `aria-expanded`, `aria-controls` et pointer vers un élément `role="listbox"`.
- **Contrastes Marianne :** Ratios de contraste $\ge 4.5:1$ en mode clair comme en mode sombre (`#000091` sur fond clair, `#8585f6` sur fond sombre).
