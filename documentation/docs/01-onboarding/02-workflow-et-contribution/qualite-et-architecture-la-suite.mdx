## 🛠️ 4. Commande Unifiée de Validation (`make check`)

Pour garantir qu'aucun commit ne dégrade la qualité, la commande unique suivante valide l'intégralité de la chaîne :

```bash
make check
```

Elle exécute séquentiellement :
1. Compilation des packages TypeScript (`make packages-build`).
2. Tests unitaires TypeScript (`make packages-test`).
3. Build de production de la démo (`make demo-build`).
4. Tests E2E Playwright (`npm run test:e2e`).
5. Tests backend Django (`pytest` avec 46 tests de sécurité SSRF et API).
6. Compilation SSR de la documentation (`make docs-build`).
