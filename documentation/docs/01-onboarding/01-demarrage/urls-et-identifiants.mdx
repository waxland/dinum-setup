## 🔐 3. Fournisseurs d'Authentification (SSO & Keycloak)

En développement local, l'authentification OpenID Connect (OIDC) est assurée par des instances Keycloak locales pré-configurées :

| Instance Keycloak            | URL d'accès                                                                                          | Realm par défaut | Identifiants Console Admin |
| ---------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------- | -------------------------- |
| **Keycloak Docs & Projects** | [http://localhost:8080](http://localhost:8080) (ou [http://auth.local:8080](http://auth.local:8080)) | `impress`        | `admin` / `admin`          |
| **Keycloak Transfers**       | [http://localhost:8902](http://localhost:8902)                                                       | `transfers`      | `admin` / `admin`          |

> 🌐 **Résolution DNS locale :**  
> Pour que le SSO fonctionne sans encombre entre votre machine hôte et Docker, ajoutez la ligne suivante dans `/etc/hosts` :
>
> ```text
> 127.0.0.1 auth.local
> ```

## 🐘 4. Bases de Données (PostgreSQL 16)

Chaque service dispose de sa propre base de données PostgreSQL isolée dans un conteneur.

| Service / Projet   | Hôte        | Port Local           | Nom de BDD  | Utilisateur | Mot de passe | URL de connexion (`DATABASE_URL`)                          |
| ------------------ | ----------- | -------------------- | ----------- | ----------- | ------------ | ---------------------------------------------------------- |
| **Docs (Impress)** | `localhost` | **`15432`**          | `impress`   | `impress`   | `password`   | `postgresql://impress:password@localhost:15432/impress`    |
| **Keycloak SSO**   | `localhost` | **`5433`**           | `keycloak`  | `keycloak`  | `password`   | `postgresql://keycloak:password@localhost:5433/keycloak`   |
| **Projects**       | `localhost` | **`5432`**           | `projects`  | `postgres`  | `postgres`   | `postgresql://postgres:postgres@localhost:5432/projects`   |
| **Transfers**      | `localhost` | **`5432`**           | `transfers` | `transfers` | `password`   | `postgresql://transfers:password@localhost:5432/transfers` |
| **People**         | `localhost` | **`15432`** / `5432` | `people`    | `people`    | `password`   | `postgresql://people:password@localhost:15432/people`      |
| **Accounts**       | `localhost` | **`15432`** / `5432` | `accounts`  | `accounts`  | `password`   | `postgresql://accounts:password@localhost:15432/accounts`  |

> 💡 **Remarque sur les ports :**
>
> - Le port **`15432`** pour Docs et **`5433`** pour Keycloak évitent les conflits avec toute instance PostgreSQL locale native tournant déjà sur le port par défaut `5432`.

> 💡 **Connexion en 1 clic dans VS Code :**  
> Toutes ces bases de données sont pré-configurées dans `.vscode/settings.json`. Installez **SQLTools** (`mtxr.sqltools`) et son driver **SQLTools PostgreSQL Driver** (`mtxr.sqltools-driver-pg`) pour vous y connecter instantanément depuis l'éditeur (voir [Guide de configuration VS Code](/01-onboarding/01-demarrage/vscode)).
