**Grist** est l'outil hybride combinant la simplicité d'un tableur et la puissance d'une base de données relationnelle no-code, permettant aux équipes métiers de concevoir des outils de gestion personnalisés (suivi de recrutement, gestion de subventions, inventaires, plannings).

## 🐍 2. Formules Python Intégrées

Contrairement aux tableurs traditionnels limités par des syntaxes complexes de formules propriétaires, Grist exécute un environnement **Python standard** sécurisé dans un sandbox WebAssembly :

```python
import datetime

def calculer_statut(rec):
    if rec.DateValidation:
        return "Validé"
    elif rec.DateLimite and rec.DateLimite < datetime.date.today():
        return "En retard"
    return "En cours"
```

## 🔒 3. Sécurité & Droits d'Accès Granulaires

Grist permet d'écrire des règles de sécurité déclaratives basées sur l'identité de l'agent connecté :

| Règle / Cas d'usage                               | Formule de politique d'accès                   |
| ------------------------------------------------- | ---------------------------------------------- |
| **Lecture seule de ses propres dossiers**         | `user.Email == rec.AgentEmail`                 |
| **Masquage de colonnes confidentielles**          | `user.Role == "Administrateur"`                |
| **Interdiction de modification après validation** | `not rec.IsLocked or user.Role == "Direction"` |

## 🌐 4. Intégration dans La Suite numérique

- **Authentification SSO :** Connexion transparente via **ProConnect**.
- **Partage inter-équipes :** Intégration avec l'annuaire d'agents **People** et les espaces d'équipe **Projects**.
- **Stockage Souverain :** Fichiers `.grist` (bases SQLite optimisées) sauvegardés et chiffrés sur le cluster S3 souverain.
