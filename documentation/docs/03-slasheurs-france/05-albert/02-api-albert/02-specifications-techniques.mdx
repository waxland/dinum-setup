## 📡 1. Endpoints & Contrat d'Échange REST

### `POST /v1/chat/completions` (Mode RAG Souverain)

#### En-têtes HTTP Requis :
```http
Authorization: Bearer <ALBERT_API_KEY>
Content-Type: application/json
X-Source-Application: LaSuiteDocs-Sources
```

#### Schéma de la Requête (Request Body) :
```json
{
  "model": "albert-large-fr",
  "messages": [
    {
      "role": "system",
      "content": "Tu es l'assistant souverain Albert. Réponds uniquement à partir des corpus publics certifiés."
```

## 🛡️ 2. Gestion des Quotas & Circuit Breaker

<Mermaid chart={`flowchart LR
    Request["Requête /albert"] --> CircuitBreaker{"Circuit Breaker<br/>(Timeout 3.5s)"}
    CircuitBreaker -->|Nominal| LiveAPI["API Albert RAG"]
    CircuitBreaker -->|Timeout ou 5xx| FallbackMock["Mock RAG Certifié (Local)"]
    LiveAPI --> Cache[("Redis Cache TTL 24h")]
    FallbackMock --> Cache
`} />

- **Timeout strict :** 3 500 ms sur la passerelle API.
- **Cache Redis :** 24 heures par hachage SHA-256 de la requête en minuscules et tokenisée.
- **Fallback défensif :** En cas d'indisponibilité, bascule automatique sur le dictionnaire de synthèse certifiée sans bloquer l'agent.
