## 📊 Matrice d'Évaluation des APIs

| API | Opérateur | Type d'Entités | Latence | Statut |
| :--- | :--- | :--- | :--- | :---: |
| **API Annuaire DILA** | DILA / Service-Public | Administrations, Mairies, Tribunaux | Moins de 80 ms | 🟢 **Source Principale** |
| **La Suite People** | DINUM | Agents publics individuels | Moins de 50 ms | 🟢 Fédération Suite |
| **Sirene Entreprises Publiques** | INSEE | Établissements publics | Moins de 100 ms | 🟡 Données légales seules |

## 💡 Choix Technique
L'API **`api-lannuaire.service-public.fr`** constitue la référence nationale pour les coordonnées des organismes publics.
