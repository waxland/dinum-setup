## 🏛️ 1. Le Référentiel National de l'Administration

L'**Annuaire de l'Administration**, administré par la **DILA** (Direction de l'Information Légale et Administrative), constitue la base de données unique et souveraine répertoriant :
- Les **administrations centrales** et ministères.
- Les **services déconcentrés** de l'État (Préfectures, Rectorats, DREAL, DDFiP).
- Les **juridictions**, ambassades et consulats.
- Les **organismes publics locaux** (Mairies, EPCI, CCAS, CPAM, CAF).

## 📋 2. Données Certifiées Disponibles

| Donnée | Type | Rôle dans l'Éditeur |
| :--- | :--- | :--- |
| **Nom Officiel** | Chaîne normalisée | Titre du bloc |
| **Catégorie d'Organisme** | Code DILA | Badge institutionnel |
| **Adresse Postale** | Adresse certifiée | Coordonnées de contact |
| **Courriel & Téléphone** | Contact public | Bouton d'action direct |
| **Horaires d'Ouverture** | Plages d'accueil | Métadonnée pratique |
