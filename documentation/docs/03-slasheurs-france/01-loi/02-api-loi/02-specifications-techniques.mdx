L'API Légifrance officielle est hébergée sur la plateforme interministérielle **PISTE** (_Plateforme d'Intermédiation des Services pour la Transformation de l'État_) opérée par la DILA.

## 📡 Endpoints & Requêtes Types

### Endpoint `/suggest` (Autocomplétion pendant la saisie)

```http
POST https://api.piste.gouv.fr/dila/legifrance/lf-engine-app/suggest
Authorization: Bearer <ACCESS_TOKEN>
Content-Type: application/json

{
  "searchText": "pouvoir du prefet",
  "supplies": ["ALL_SUGGEST"]
}
```

### Endpoint `/search` (Recherche Structurée & Filtres)

```http
POST https://api.piste.gouv.fr/dila/legifrance/lf-engine-app/search
Authorization: Bearer <ACCESS_TOKEN>
Content-Type: application/json

{
  "fond": "LODA_DATE",
  "recherche": {
    "champs": [
      {
        "typeChamp": "ALL",
        "criteres": [
          {
            "typeRecherche": "TOUS_LES_MOTS_DANS_UN_CHAMP",
            "valeur": "commande publique",
            "operateur": "ET"
          }
        ],
        "operateur": "ET"
      }
    ],
    "pageNumber": 1,
    "pageSize": 5,
    "sort": "PERTINENCE"
  }
}
```

## 🗺️ Mapping des Fonds Documentaires

| Filtre UI | `supplies` (`/suggest`) | `fond` (`/search`) | Description |
| :--- | :--- | :--- | :--- |
| **Tous** | `ALL_SUGGEST` | `ALL` | Ensemble des collections juridiques |
| **Codes** | `CODE_LIST` | `CODE_DATE` | Codes juridiques en vigueur à date |
| **Lois & Décrets** | `LODA_LIST` | `LODA_DATE` | Textes législatifs et réglementaires |
| **Journal Officiel** | `JORF_SUGGEST` | `JORF` | Publications au Journal Officiel |
| **Conseil d'État** | `CETAT` | `CETAT` | Jurisprudence administrative |
| **Cassation** | `JURI` | `JURI` | Jurisprudence judiciaire |
