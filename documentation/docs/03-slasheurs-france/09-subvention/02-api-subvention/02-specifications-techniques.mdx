## 📡 1. Endpoint de Recherche

### `GET https://aides-territoires.beta.gouv.fr/api/aides/`

#### Paramètres :
- `text` : Mots-clés de recherche.
- `perimeter` : Code INSEE de la commune ou département ciblé.
- `targeted_audiences` : `commune`, `epci`, `department`, `region`.

#### Réponse JSON :
```json
{
  "count": 1,
  "results": [
    {
      "id": 14285,
      "name": "Fonds Vert - Rénovation énergétique des bâtiments publics",
      "financers": ["État (Direction Générale des Collectivités Locales)"],
      "subvention_rate_max": 80,
      "submission_deadline": "2026-11-30",
      "application_url": "https://www.demarches-simplifiees.fr/commencer/fonds-vert-2026"
    }
  ]
}
```
