## 🐍 L'Interface Abstraite `BaseSourceProvider` (`sources/base.py`)

Tous les providers implémentent un contrat strict garantissant que les données retournées sont immédiatement compatibles avec le composant React `SourceBlockSpec` :

```python
from abc import ABC, abstractmethod
from typing import TypedDict, Optional

class SourceSearchResult(TypedDict):
    source_id: str
    source_type: str        # 'law' | 'company' | 'parliament' | 'address'
    provider: str
    title: str
    subtitle: Optional[str]
    status: str
    status_badge_color: str # 'info' | 'success' | 'warning' | 'error'
    content_html: Optional[str]
    summary: Optional[str]
    meta_field_1_label: Optional[str]
    meta_field_1_value: Optional[str]
    meta_field_2_label: Optional[str]
    meta_field_2_value: Optional[str]
    meta_field_3_label: Optional[str]
    meta_field_3_value: Optional[str]
    url: str

class BaseSourceProvider(ABC):
    provider_id: str = ""
    source_type: str = ""

    @abstractmethod
    def is_enabled(self) -> bool:
        """Vérifie si le provider est activé (clés API présentes dans .env ou Mock)."""
        pass

    @abstractmethod
    def suggest(self, query: str, limit: int = 5) -> list[dict]:
        """Autocomplétion rapide pendant la frappe (< 100ms)."""
        pass

    @abstractmethod
    def search(self, query: str, limit: int = 10) -> list[SourceSearchResult]:
        """Recherche complète retournant des entités normalisées."""
        pass

    @abstractmethod
    def get_detail(self, source_id: str) -> Optional[SourceSearchResult]:
        """Récupère le détail complet d'une entité par son identifiant unique."""
        pass
```

## 🛣️ La Vue DRF Générique (`sources/views.py`)

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework.permissions import IsAuthenticated
from django.core.cache import cache
import hashlib
from .registry import source_provider_registry

class SourceSearchView(APIView):
    permission_classes = [IsAuthenticated]

    def get(self, request):
        source_type = request.query_params.get("type", "law")
        query = request.query_params.get("q", "").strip()

        if len(query) < 2:
            return Response({"results": []})

        provider = source_provider_registry.get_provider(source_type)
        if not provider or not provider.is_enabled():
            return Response(
                {"error": f"Le provider pour '{source_type}' n'est pas activé sur ce serveur."},
                status=404,
            )

        # Hash unique de la requête pour la clé Redis
        query_hash = hashlib.md5(f"{source_type}:{query}".encode()).hexdigest()
        cache_key = f"source:search:{query_hash}"

        cached_results = cache.get(cache_key)
        if cached_results is not None:
            return Response({"results": cached_results, "from_cache": True})

        try:
            results = provider.search(query)
            cache.set(cache_key, results, timeout=86400)  # 24h
            return Response({"results": results, "from_cache": False})
        except Exception as exc:
            return Response(
                {"error": "Erreur lors de l'interrogation de la source.", "details": str(exc)},
                status=502,
            )
```

## ⚡ Gestion Distribuée des Quotas & Circuit Breaker

Pour protéger les quotas des APIs ministérielles et garantir qu'un document ne soit jamais bloqué en cas de panne d'un fournisseur tiers, le backend intègre le **`DistributedQuotaManager`** (`lasuite_sources/quota.py`) :

<Mermaid chart={`stateDiagram-v2
    [*] --> HEALTHY
    HEALTHY --> DEGRADED : Quota journalier > 80% consommé
    DEGRADED --> HEALTHY : Réinitialisation quotidienne du quota
    DEGRADED --> QUOTA_EXHAUSTED : Quota journalier 100% consommé
    HEALTHY --> QUOTA_EXHAUSTED : Quota 100% consommé
    
    HEALTHY --> CIRCUIT_OPEN : Échecs 5xx répétés (3x) ou Timeout (3.5s)
    HEALTHY --> CIRCUIT_OPEN : HTTP 429 Too Many Requests (avec Retry-After)
    DEGRADED --> CIRCUIT_OPEN : HTTP 429 / 5xx
    
    CIRCUIT_OPEN --> HALF_OPEN : Délai de refroidissement écoulé (30s à 60s)
    HALF_OPEN --> HEALTHY : Requête de test réussie
    HALF_OPEN --> CIRCUIT_OPEN : Échec de la requête de test
`} />

### 🛡️ Niveaux de Protection & Règles de Résilience :

1. **Seuil de Sécurité à 80% :** À 80% du quota consommé, le connecteur bascule en mode `DEGRADED` (recherche en cache prioritaire) pour conserver 20% de marge pour les résolutions détaillées critiques.
2. **Rate Limiting Burst par Utilisateur :** Limitation à 60 requêtes/minute par utilisateur/IP pour empêcher qu'un client n'épuise le quota global partagé.
3. **Interception HTTP 429 & `Retry-After` :** Le circuit breaker s'ouvre immédiatement pour la durée demandée par le fournisseur distant sans relancer d'appels réseau inutiles.
4. **Persistance Immuable du Bloc :** Toute entité insérée dans BlockNote conserve un instantané complet (`title`, `excerpt`, `meta1..3`, `url`, `verifiedAt`) : le document s'affiche toujours parfaitement même si l'API est indisponible.

## ⚡ Feature Flagging Centralisé

L'endpoint `/api/v1/config/features/` liste dynamiquement les providers actifs à destination du frontend :

```python
class FeatureFlagsConfigView(APIView):
    permission_classes = []

    def get(self, request):
        active_providers = source_provider_registry.get_enabled_source_types()
        return Response({
            "features": {
                "slash_sources": {
                    "enabled": len(active_providers) > 0,
                    "active_types": active_providers,  # ['law', 'company', 'parliament']
                }
            }
        })
```
