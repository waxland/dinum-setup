## 📡 1. Endpoints de Recherche BOAMP

### `GET /api/v1/boamp/avis/search`

#### Paramètres de Requête :
- `q` : Chaîne de recherche (mots-clés, numéro AAPC).
- `famille` : `FPA` (Formulaire Standard), `MAPA` (Procédure Adaptée).
- `limit` : Nombre de résultats (défaut : 10).
