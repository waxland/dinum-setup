## ⚙️ 1. Variables d'Environnement

```ini
SOURCES_INSEE_API_URL=https://api.insee.fr/donnees-locales/V0.1
SOURCES_INSEE_API_KEY=votre_cle_api_insee
SOURCES_GEO_API_URL=https://geo.api.gouv.fr
SOURCES_INSEE_CACHE_TTL=86400
```

## 🎨 2. Rendu des 3 Formats DSFR

1. **🗂️ Carte 3 Colonnes :** Population municipale • Densité • Revenu médian annuel.
2. **📢 Encadré Marianne :** Résumé démographique certifié avec bordure Marianne `#000091`.
3. **🔗 Pastille Lien :** `📊 Rennes (222 485 hab - INSEE)`.
