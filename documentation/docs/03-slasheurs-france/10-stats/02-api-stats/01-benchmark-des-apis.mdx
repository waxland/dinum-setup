## 📊 Matrice Comparative des APIs

| API | Opérateur | Couverture | Latence | Fiabilité |
| :--- | :--- | :--- | :--- | :---: |
| **API Données Locales INSEE** | INSEE | Toutes les communes | Moins de 150 ms | 🟢 **Source Primaire** |
| **GeoAPI (geo.api.gouv.fr)** | DINUM / Etalab | Découpage administratif | Moins de 50 ms | 🟢 Complément Géographique |
| **Fichiers Millésimés INSEE** | data.gouv.fr | Annuel | Batch | 🟡 Source d'archive |

## 💡 Architecture Retenue
Le provider combine l'API **geo.api.gouv.fr** pour l'autocomplétion ultrarapide des noms de communes et l'API **INSEE Données Locales** pour l'extraction certifiée des indicateurs socio-économiques.
