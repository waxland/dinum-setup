**[BlockNote](https://www.blocknotejs.org/)** est la bibliothèque open-source moderne de composants d'édition de texte par blocs (style _Notion_) sur laquelle repose le cœur d'édition de **La Suite Docs**. Conçue en TypeScript au-dessus de **ProseMirror** et **TipTap**, elle intègre nativement la collaboration en temps réel décentralisée via **Yjs**.

- **Site officiel :** [https://www.blocknotejs.org/](https://www.blocknotejs.org/)
- **Documentation officielle :** [https://www.blocknotejs.org/docs](https://www.blocknotejs.org/docs)
- **Dépôt GitHub :** [TypeCellOS/BlockNote](https://github.com/TypeCellOS/BlockNote) (Licence MPL-2.0 / MIT)
- **Intégration dans La Suite :** Utilisé dans le frontend Next.js de `suitenumerique/docs`

## 📦 2. Installation & Dépendances

Dans un projet React / Next.js utilisant Tailwind CSS et le DSFR :

```bash
# Core BlockNote et adaptateur React
pnpm add @blocknote/core @blocknote/react

# UI de base (au choix: Mantine ou Shadcn/Tailwind)
pnpm add @blocknote/mantine @mantine/core
```

## 🔍 3. Audit & Guide : Ajouter une Commande Slash Custom (`/law` Légifrance)

### 🎯 Problématique Métier

Dans les administrations françaises, les agents rédigent quotidiennement des notes de cadrage, des cahiers des charges et des délibérations faisant référence aux textes de lois officiels (Code des marchés publics, RGPD, Code général de la fonction publique).

**Objectif :** Permettre à l'agent de taper `/law` ou `/loi` dans l'éditeur Docs pour rechercher et insérer un **bloc officiel Légifrance certifié** sans jamais modifier ni forker le code source de la bibliothèque `BlockNote`.

---

### 🧩 Étape 1 : Créer le Composant de Bloc Personnalisé (`LawBlock.tsx`)

Grâce à `createReactBlockSpec`, vous définissez le schéma de données (qui sera automatiquement répliqué en CRDT Yjs) et le rendu React avec le style officiel **DSFR** :

```tsx
import { createReactBlockSpec } from "@blocknote/react";

// 1. Définition du schéma typé du bloc de loi
export const LawBlock = createReactBlockSpec(
  {
    type: "law",
    propSchema: {
      codeName: {
        default: "Code de la commande publique",
      },
      articleNumber: {
        default: "Article L. 2122-1",
      },
      legifranceUrl: {
        default:
          "https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037728472",
      },
      excerpt: {
        default:
          "L'acheteur peut passer un marché sans publicité ni mise en concurrence préalables...",
      },
      status: {
        default: "En vigueur",
      },
    },
    content: "none",
  },
  {
    render: (props) => {
      const { codeName, articleNumber, legifranceUrl, excerpt, status } =
        props.block.props;

      return (
        <div className="fr-callout fr-callout--blue-france my-4 p-4 border-l-4 border-[#000091] bg-blue-50/50 dark:bg-blue-950/20 rounded-r-lg">
          <div className="flex items-center justify-between gap-2 mb-2">
            <div className="flex items-center gap-2">
              <span className="text-xl">⚖️</span>
              <h4 className="fr-callout__title text-base font-bold text-[#000091] dark:text-[#8585f6] m-0">
                {codeName} — {articleNumber}
              </h4>
            </div>
            <span className="fr-badge fr-badge--success fr-badge--sm text-xs px-2 py-0.5 rounded bg-emerald-100 text-emerald-800 dark:bg-emerald-950 dark:text-emerald-300">
              {status}
            </span>
          </div>

          <p className="fr-callout__text text-sm italic text-gray-700 dark:text-gray-300 mb-3 border-l-2 border-gray-300 dark:border-gray-700 pl-3">
            « {excerpt} »
          </p>

          <div className="flex items-center justify-end">
            <a
              href={legifranceUrl}
              target="_blank"
              rel="noopener noreferrer"
              className="fr-link text-xs font-semibold text-[#000091] dark:text-[#8585f6] hover:underline flex items-center gap-1"
            >
              <span>Consulter sur Légifrance</span>
              <span>↗</span>
            </a>
          </div>
        </div>
      );
    },
  },
);
```

### ⚙️ Étape 2 : Déclarer le Schéma Étendu de l'Éditeur

Combinez les blocs par défaut de BlockNote avec votre nouveau bloc `law` :

```tsx
import { BlockNoteSchema, defaultBlockSpecs } from "@blocknote/core";
import { LawBlock } from "./LawBlock";

// Schéma consolidé sans toucher à la librairie upstream
export const customSchema = BlockNoteSchema.create({
  blockSpecs: {
    ...defaultBlockSpecs,
    law: LawBlock,
  },
});
```

### 🪄 Étape 3 : Définir l'Élément du Menu Slash (`insertLawSlashItem`)

BlockNote expose la fonction `getDefaultSlashMenuItems` qui peut être filtrée et enrichie avec vos propres commandes :

```tsx
import { getDefaultSlashMenuItems } from "@blocknote/react";
import type { customSchema } from "./schema";

export const insertLawSlashItem = (
  editor: typeof customSchema.BlockNoteEditor,
) => ({
  title: "Texte de Loi (Légifrance)",
  onItemClick: async () => {
    // Exemple : simulation de sélection ou appel API Légifrance (DILA / PISTE)
    editor.insertBlocks(
      [
        {
          type: "law",
          props: {
            codeName: "Code général de la fonction publique",
            articleNumber: "Article L. 111-1",
            legifranceUrl:
              "https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044414167",
            excerpt:
              "Les agents publics sont au service de la Nation et de l'intérêt général.",
            status: "En vigueur",
          },
        },
      ],
      editor.getTextCursorPosition().block,
      "after",
    );
  },
  aliases: ["law", "loi", "legifrance", "juridique", "article", "droit"],
  group: "Administration & Souveraineté",
  icon: <span>⚖️</span>,
  subtext: "Lier et certifier un article de loi officiel Légifrance",
});
```

### 💻 Étape 4 : Intégration dans la Vue React

```tsx
import "@blocknote/core/fonts/inter.css";
import "@blocknote/mantine/style.css";
import { BlockNoteView } from "@blocknote/mantine";
import {
  useCreateBlockNote,
  SuggestionMenuController,
  getDefaultSlashMenuItems,
} from "@blocknote/react";
import { customSchema } from "./schema";
import { insertLawSlashItem } from "./slashItems";

export function DocsEditor({ ydoc, provider }: { ydoc: any; provider: any }) {
  // 1. Initialisation avec le schéma custom et le transport Yjs
  const editor = useCreateBlockNote({
    schema: customSchema,
    collaboration: {
      provider,
      fragment: ydoc.getXmlFragment("document-store"),
      user: {
        name: "Agent Public (DINUM)",
        color: "#000091",
      },
    },
  });

  return (
    <div className="w-full bg-white dark:bg-gray-900 rounded-xl border border-gray-200 dark:border-gray-800 shadow-sm p-4">
      <BlockNoteView editor={editor} slashMenu={false}>
        {/* 2. Injection du contrôleur de menu slash personnalisé */}
        <SuggestionMenuController
          triggerCharacter="/"
          getItems={async (query) => {
            const defaultItems = getDefaultSlashMenuItems(editor);
            const customItems = [insertLawSlashItem(editor)];

            return [...defaultItems, ...customItems].filter(
              (item) =>
                item.title.toLowerCase().includes(query.toLowerCase()) ||
                item.aliases?.some((a) =>
                  a.toLowerCase().includes(query.toLowerCase()),
                ),
            );
          }}
        />
      </BlockNoteView>
    </div>
  );
}
```

## ⚡ 5. Synthèse des Avantages de cette Approche

1. **Zéro Forking, Zéro Dette :** Aucune modification des fichiers dans `node_modules` ou des sources upstream de BlockNote. Les mises à jour de version (`pnpm update @blocknote/core`) restent 100% transparentes.
2. **Synchronisation CRDT Automatique :** Le bloc `law` hérite nativement du moteur de réplication Yjs. Si deux agents éditent le même document, le bloc de loi s'affiche et se met à jour en temps réel sur tous les écrans.
3. **Design System Respecté :** Le composant `render` du bloc utilise directement les classes et tokens du **DSFR** (`fr-callout`, `fr-badge`, `#000091`).
4. **Accessibilité Maximale :** Les liens vers Légifrance et les balises de citation respectent les critères du RGAA v4.1.
