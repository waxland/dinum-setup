# Transfers

**Transfers** est le service d'envoi et de partage sécurisé de fichiers volumineux de La Suite numérique.

- **Dépôt GitHub :** [suitenumerique/transfers](https://github.com/suitenumerique/transfers)

## Statut d'intégration

- **Clone :** Supporté via `REPOS="transfers" make clone`
- **Env & Dev :** Consultez le `README.md` du dépôt d'origine sous `src/transfers` pour les instructions manuelles.
