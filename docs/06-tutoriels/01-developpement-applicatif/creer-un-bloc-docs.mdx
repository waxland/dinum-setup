Ce tutoriel vous guide dans la création d'un composant de bloc personnalisé pour l'éditeur collaboratif **La Suite Docs**, basé sur le framework open-source **BlockSuite**.

---

## 🎯 Objectif : Le Bloc « Décision d'Équipe »

Nous allons implémenter un bloc interactif permettant de formaliser une décision d'arbitrage avec un titre, un statut (_Proposé_, _Validé_, _Rejeté_) et un compteur de votes en temps réel.

---

## 1. Définition du Schéma de Modèle de Données (CRDT)

Créez le fichier de schéma `src/blocks/decision/decision-schema.ts` :

```typescript
import { BlockSchemaType, defineBlockSchema } from "@blocksuite/store";

export type DecisionProps = {
  title: string;
  status: "proposed" | "approved" | "rejected";
  votes: Record<string, boolean>; // userId -> a voté pour
};

export const DecisionBlockSchema = defineBlockSchema({
  flavour: "affine:decision",
  props: (): DecisionProps => ({
    title: "",
    status: "proposed",
    votes: {},
  }),
  metadata: {
    version: 1,
    role: "content",
    parent: ["affine:note", "affine:surface"],
    children: [],
  },
});
```

---

## 2. Implémentation du Composant d'Affichage UI

Créez la vue du composant `src/blocks/decision/decision-block.ts` :

```typescript
import { BlockElement } from "@blocksuite/block-std";
import { html } from "lit";
import { customElement } from "lit/decorators.js";
import { DecisionBlockSchema, type DecisionProps } from "./decision-schema";

@customElement("affine-decision-block")
export class DecisionBlockComponent extends BlockElement<DecisionProps> {
  static override schema = DecisionBlockSchema;

  private handleVote() {
    const currentUserId =
      this.doc.awarenessStore.getLocalUser()?.id ?? "anonymous";
    const currentVotes = { ...this.model.votes };

    if (currentVotes[currentUserId]) {
      delete currentVotes[currentUserId];
    } else {
      currentVotes[currentUserId] = true;
    }

    // Mise à jour transactionnelle dans le CRDT Yjs
    this.doc.transact(() => {
      this.model.votes = currentVotes;
    });
  }

  override render() {
    const voteCount = Object.keys(this.model.votes).length;

    return html`
      <div class="fr-callout fr-callout--blue-france my-4">
        <h4 class="fr-callout__title">
          ${this.model.title || "Décision sans titre"}
        </h4>
        <p class="fr-callout__text">
          Statut actuel : <strong>${this.model.status}</strong>
        </p>
        <button
          class="fr-btn fr-btn--secondary fr-btn--sm"
          @click=${this.handleVote}
        >
          👍 Voter pour (${voteCount})
        </button>
      </div>
    `;
  }
}
```

---

## 3. Enregistrement dans le Registre de Blocs

Ajoutez votre nouveau bloc dans `src/editor/block-registry.ts` :

```typescript
import { BlockViewExtension } from "@blocksuite/block-std";
import { literal } from "lit/static-html.js";
import { DecisionBlockSchema } from "./decision/decision-schema";

export const DecisionBlockExtension = BlockViewExtension(
  DecisionBlockSchema.model.flavour,
  literal`affine-decision-block`,
);
```

Votre bloc est désormais synchronisé en temps réel, persistant et prêt pour l'édition collaborative !
