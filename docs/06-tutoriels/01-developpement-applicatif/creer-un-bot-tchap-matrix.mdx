Ce tutoriel détaille la création d'un robot de messagerie capable de poster des alertes d'astreinte ou de répondre à des commandes textuelles sur les salons **Tchap**.

---

## 📦 1. Installation du SDK Matrix

```bash
pnpm add matrix-js-sdk dotenv
pnpm add -D @types/node typescript
```

---

## 🤖 2. Code du Bot (`src/bot-tchap.ts`)

```typescript
import * as sdk from "matrix-js-sdk";
import * as dotenv from "dotenv";

dotenv.config();

const HOMESERVER_URL =
  process.env.TCHAP_HOMESERVER || "https://matrix.agent.dinum.tchap.gouv.fr";
const BOT_ACCESS_TOKEN = process.env.TCHAP_BOT_TOKEN!;
const BOT_USER_ID = process.env.TCHAP_BOT_USER_ID!;

async function main() {
  const client = sdk.createClient({
    baseUrl: HOMESERVER_URL,
    accessToken: BOT_ACCESS_TOKEN,
    userId: BOT_USER_ID,
  });

  // Démarrer la boucle de synchronisation Matrix
  await client.startClient({ initialSyncLimit: 10 });

  client.once("sync", (state) => {
    if (state === "PREPARED") {
      console.log("🤖 Bot Tchap connecté et prêt à écouter les messages !");
    }
  });

  // Écouter les nouveaux messages dans les salons
  client.on("Room.timeline", (event, room, toStartOfTimeline) => {
    if (toStartOfTimeline) return;
    if (event.getType() !== "m.room.message") return;
    if (event.getSender() === BOT_USER_ID) return; // Ne pas répondre à soi-même

    const body = event.getContent().body?.trim();
    const roomId = room.roomId;

    if (body === "!ping") {
      client.sendTextMessage(roomId, "🏓 Pong ! Bot La Suite opérationnel.");
    } else if (body === "!aide") {
      client.sendHtmlMessage(
        roomId,
        "Commandes disponibles : <code>!ping</code>, <code>!statut</code>, <code>!deploiement</code>",
        "<h3>Aide du Bot La Suite</h3><ul><li>!ping</li><li>!statut</li></ul>",
      );
    }
  });
}

main().catch(console.error);
```

## 📢 3. Envoi d'une Notification Automatisée (Webhook / CI)

Pour diffuser une notification après un déploiement réussi :

```typescript
export async function sendDeploymentAlert(
  roomId: string,
  appName: string,
  version: string,
) {
  const client = sdk.createClient({
    baseUrl: HOMESERVER_URL,
    accessToken: BOT_ACCESS_TOKEN,
    userId: BOT_USER_ID,
  });

  await client.sendNotice(
    roomId,
    `🚀 Déploiement réussi de ${appName} en version ${version} sur l'infrastructure SecNumCloud !`,
  );
}
```
