# Meet (Visio)

**Meet** est le service de visioconférence sécurisé de La Suite numérique.

- **Dépôt GitHub :** [suitenumerique/meet](https://github.com/suitenumerique/meet)
- **Stack technique :** LiveKit, WebRTC, React, TypeScript.

## Statut d'intégration

- **Clone :** Supporté via `REPOS="meet" make clone`
- **Env :** Partiel (`make env-meet`)
- **Dev :** Manuel à ce stade (nécessite une configuration LiveKit et OIDC dédiée).
