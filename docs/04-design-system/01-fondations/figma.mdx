## 🛠️ Le Design System Cunningham dans La Suite Docs

L'application **Docs** (`impress`) s'appuie fondamentalement sur **Cunningham** pour l'ensemble de son interface :

1. **Génération de Tokens CSS & TypeScript :**  
   Les tokens de couleurs, typographie, espacements et formes sont compilés via la CLI Cunningham :
   ```bash
   cunningham -g css,ts -o src/cunningham --utility-classes
   ```
2. **Tokens de Design Universels :**  
   Toutes les valeurs de style utilisent les CSS Custom Properties standardisées :
   - `--c--globals--colors--brand-primary` / `--c--globals--colors--gray-700`
   - `--c--globals--spacings--3xs` / `--c--globals--spacings--md`
   - `--c--globals--font--sizes--sm` / `--c--globals--font--sizes--md`
3. **Composant Conteneur `<Box>` (`src/components/Box.tsx`) :**  
   Pratique standard dans l'éditeur pour construire toutes les cartes, modales, boutons et barres d'outils avec `styled-components`.
