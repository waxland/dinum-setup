## 🛠️ 2. Utilisation de la Librairie Figma La Suite

### Accéder au kit communautaire

1. Ouvrez le fichier communautaire : **[La Suite UI Kit sur Figma Community](https://www.figma.com/community/file/1562860630562131728/lasuite-ui-kit)**.
2. Cliquez sur **Open in Figma** pour dupliquer le fichier dans votre espace de travail.
3. Activez la librairie dans vos projets pour accéder à l'ensemble des composants :
   - Boutons & Variantes (Primary, Secondary, Tertiary, Bordered)
   - Bouton d'authentification **ProConnect**
   - Badges, Tags et Puces de statut
   - Modales, Toasts et Bannières d'alerte
   - Grilles et tokens d'espacement

## 💻 3. Correspondance entre Figma et Code React

Le kit de composants Figma correspond directement aux packages React développés par l'équipe :

| Composant Figma       | Package React Officiel                                            | Visualisation Storybook                                                                                        |
| --------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Buttons**           | `@gouvfr-lasuite/ui-components` / `@codegouvfr/react-dsfr/Button` | [Voir la démo Storybook](https://suitenumerique.github.io/ui-kit/?path=/docs/components-button--docs)          |
| **ProConnect Button** | `@gouvfr-lasuite/ui-components`                                   | [Voir la démo ProConnect](https://suitenumerique.github.io/ui-kit/?path=/story/components-button--pro-connect) |
| **Typography**        | Police Marianne (`@gouvfr/dsfr/dist/fonts/`)                      | [Guide Typographie](/04-design-system/01-fondations/typographie)                                               |
| **Tokens & Couleurs** | Variables CSS `--blue-france-sun-113`, etc.                       | [Guide Couleurs](/04-design-system/01-fondations/couleurs-et-themes)                                           |

## 🔤 4. Typographie & Charte de l'État

La typographie **Marianne** est la police officielle obligatoire pour tous les services publics et interfaces de l'État :

- 👉 **[Règles officielles de la typographie sur info.gouv.fr](https://www.info.gouv.fr/marque-de-letat/la-typographie)**
- Téléchargements des formats OTF et TTF légaux pour utilisation dans vos logiciels de design (Figma, Sketch, Adobe XD).
