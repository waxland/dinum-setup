Les **Cartes** (`Card`), **Accordéons** (`Accordion`) et **Tuiles** (`Tile`) permettent d'organiser, de regrouper et de hiérarchiser visuellement des contenus et des actions dans les applications de **La Suite numérique**.

🔗 **Références officielles :** [Composant Carte DSFR](https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/carte) • [Storybook React-DSFR (Card)](https://components.react-dsfr.fr/?path=/docs/components-card--default) • [Composant Accordéon DSFR](https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/accordeon) • [Composant Tuile DSFR](https://www.systeme-de-design.gouv.fr/version-courante/fr/composants/tuile)

## 📊 1. Tableau des Variantes & Propriétés

| Composant                  | Prop React-DSFR             | Classe Core DSFR              | Usage & Rôle                                                     |
| -------------------------- | --------------------------- | ----------------------------- | ---------------------------------------------------------------- |
| **Carte standard**         | `size="medium"` (défaut)    | `fr-card`                     | Conteneur d'information avec titre, description et métadonnées.  |
| **Carte avec lien étendu** | `enlargeLink={true}`        | `fr-card fr-enlarge-link`     | Rend toute la surface de la carte cliquable via son titre.       |
| **Carte horizontale**      | `horizontal={true}`         | `fr-card fr-card--horizontal` | Disposition en ligne (image à gauche, contenu à droite).         |
| **Accordéon**              | `<Accordion label="..." />` | `fr-accordion`                | Panneau repliable pour masquer les contenus secondaires.         |
| **Tuile**                  | `<Tile title="..." />`      | `fr-tile`                     | Raccourci de navigation vers une application ou un sous-dossier. |

## 💻 2. Utilisation avec la Bibliothèque Officielle React-DSFR

```tsx
import Card from "@codegouvfr/react-dsfr/Card";
import Accordion from "@codegouvfr/react-dsfr/Accordion";
import Tile from "@codegouvfr/react-dsfr/Tile";

export function ConteneursOfficiels() {
  return (
    <div className="space-y-8">
      {/* 1. Carte interactive accessible avec lien étendu */}
      <Card
        title="Spécifications DINUM"
        desc="Consultez les spécifications techniques et les guides de contribution de La Suite numérique."
        linkProps={{
          href: "/02-architecture/index",
        }}
        detail="Mis à jour le 13/09/2026"
        size="medium"
        enlargeLink
      />

      {/* 2. Accordéon rétractable accessible */}
      <Accordion label="Détails de la configuration réseau Docker">
        <p>
          Les conteneurs applicatifs communiquent sur le réseau de pont{" "}
          <code>lasuite-network</code> via leurs alias Docker internes.
        </p>
      </Accordion>

      {/* 3. Tuile d'accès rapide */}
      <Tile
        title="Éditeur Docs (Impress)"
        desc="Ouvrir l'application de rédaction collaborative en local."
        linkProps={{
          href: "http://localhost:3000",
          target: "_blank",
        }}
      />
    </div>
  );
}
```

    </p>

## ♿ 4. Accessibilité & Critères RGAA (v4.1)

- **Pas de liens imbriqués :** Ne placez jamais de lien `<a>` ou de bouton `<button>` à l'intérieur de la description d'une carte avec `enlargeLink`.
- **Accordéons accessibles :** L'attribut `aria-expanded` est géré automatiquement par React-DSFR pour informer les lecteurs d'écran de l'état ouvert/fermé.
- **Hiérarchie des titres :** Le titre interne d'une carte doit respecter le niveau hiérarchique de la section parente (généralement `<h3>` ou `<h4>`).
