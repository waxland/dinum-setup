## 📊 1. Tableau des Variantes & Propriétés

| Propriété / Variante       | Prop React-DSFR   | Classe Core DSFR      | Usage                                                                        |
| -------------------------- | ----------------- | --------------------- | ---------------------------------------------------------------------------- |
| **Bordures complètes**     | `bordered={true}` | `fr-table--bordered`  | Ajoute un encadrement et des bordures séparatrices de cellules.              |
| **Lignes alternées**       | `noScroll={true}` | `fr-table--no-scroll` | Désactive le conteneur de défilement horizontal si le tableau est compact.   |
| **En-tête fixe / Caption** | `caption="..."`   | `<caption>`           | Titre accessible indispensable pour décrire le tableau aux lecteurs d'écran. |

## 💻 2. Utilisation avec la Bibliothèque Officielle React-DSFR

```tsx

import Badge from "@codegouvfr/react-dsfr/Badge";

  return (
    <Table
      caption="Liste des contributeurs actifs de La Suite numérique"
      headers={["Agent", "Email", "Rôle", "Statut"]}
      data={[

          "Vincent G.",
          "vincent.guerand@numerique.gouv.fr",
          "Administrateur",
          <Badge key="1" severity="success" small>
            Actif
          </Badge>,
        ],
        [
          "Damien S.",
          "damien.s@collectivite.fr",
          "Éditeur",
          <Badge key="2" severity="success" small>
            Actif
```

## ♿ 4. Accessibilité & Critères RGAA (v4.1)

- **Balise `<caption>` obligatoire (Critère 5.4) :** Tout tableau de données doit obligatoirement posséder un titre explicite sous la balise `<caption>`.
- **En-têtes de colonnes avec `scope="col"` (Critère 5.6) :** Permet aux technologies d'assistance de relier chaque cellule de données à son intitulé de colonne lors de la lecture vocale.
- **Pas de tableau pour la mise en page (Critère 5.3) :** Les tableaux ne doivent être utilisés que pour des données tabulaires réelles.
