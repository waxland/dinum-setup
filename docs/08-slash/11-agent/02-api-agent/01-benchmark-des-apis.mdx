## 📊 Matrice d'Évaluation des APIs

| API | Opérateur | Type d'Entités | Latence | Statut |
| :--- | :--- | :--- | :--- | :---: |
| **API Annuaire DILA** | DILA / Service-Public | Administrations, Mairies, Tribunaux | $< 80\text{ms}$ | 🟢 **Source Principale** |
| **La Suite People** | DINUM | Agents publics individuels | $< 50\text{ms}$ | 🟢 Fédération Suite |
| **Sirene Entreprises Publiques** | INSEE | Établissements publics | $< 100\text{ms}$ | 🟡 Données légales seules |

---

## 💡 Choix Technique
L'API **`api-lannuaire.service-public.fr`** constitue la référence nationale pour les coordonnées des organismes publics.
