## 📡 1. Endpoint de Consultation

### `GET https://api-lannuaire.service-public.fr/api/explore/v2.1/catalog/datasets/api-lannuaire-administration/records`

#### Paramètres :
- `where` : Clause de recherche textuelle et géographique.
- `limit` : Nombre d'organismes à retourner (défaut : 10).

#### Exemple de Réponse JSON :
```json
{
  "total_count": 1,
  "results": [
    {
      "id": "prefecture-35238-01",
      "nom": "Préfecture - Ille-et-Vilaine",
      "categorie": "prefecture",
      "adresse": "3 avenue de la Préfecture, 35026 Rennes Cedex 9",
      "telephone": "02 99 02 10 35",
      "email": "prefecture@ille-et-vilaine.gouv.fr",
      "url": "https://www.ille-et-vilaine.gouv.fr"
    }
  ]
}
```
