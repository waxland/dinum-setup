## 📡 1. Spécifications de l'API Albert

L'API **Albert** (`https://albert.api.etalab.gouv.fr/v1`) expose une suite d'endpoints REST sécurisés par clé d'API (Bearer Token) pour la recherche sémantique, la vectorisation et la génération augmentée.

```bash
POST /v1/search
Authorization: Bearer <ALBERT_API_KEY>
Content-Type: application/json

{
  "query": "Quel est le préavis de démission d'un agent contractuel ?",
  "collections": ["service-public", "legifrance-codes", "circulaires-sg"],
  "limit": 3,
  "generate_summary": true
}
```

### Contrat de Réponse Normalisé

```json
{
  "id": "ALBERT-RAG-FP-001",
  "query": "Quel est le préavis de démission d'un agent contractuel ?",
```

## ⚡ 2. Benchmark de Performance & Stratégie de Caching

| Métrique | Appel Direct Albert API | Avec Cache Redis Impress (24h) |
| :--- | :--- | :--- |
| **Temps de Réponse (p50)** | ~ 350 ms | **< 3 ms** |
| **Temps de Réponse (p95)** | ~ 780 ms | **< 5 ms** |
| **Coût CPU / Inférence** | 1 passe Transformer RAG | **0 (Lecture mémoire clé-valeur)** |
| **Résilience Réseau** | Dépendance externe | **100% garanti par fallback mock** |
