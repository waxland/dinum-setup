Pour alimenter la commande `/marche`, plusieurs sources d'informations publiques ont été évaluées :

---

## 📊 Matrice d'Évaluation des Sources

| Source / API | Fournisseur | Fraîcheur | Données Fournies | Statut de Rétention |
| :--- | :--- | :--- | :--- | :---: |
| **API BOAMP (DILA)** | DILA / PISTE | Temps Réel ($< 5\text{min}$) | AAPC intégraux, rectificatifs, avis d'attribution, DCE | 🟢 **Source Primaire** |
| **Dataset Marchés data.gouv.fr** | Etalab / DAE | Quotidienne ($24\text{h}$) | Historique annuel des marchés notifiés | 🟡 Source Complémentaire |
| **TED API (Tenders Electronic Daily)** | Union Européenne | Quotidienne | Marchés européens $> 143\text{k}€$ | 🟡 Source Européenne |
| **PLACE API** | DAE | Direct | Consultations actives de l'État | ⚪ Usage Interne |

---

## 💡 Choix d'Architecture
L'**API BOAMP DILA** sur la plateforme **PISTE** constitue la source officielle de référence assurant la conformité juridique et l'exhaustivité des avis nationaux.
