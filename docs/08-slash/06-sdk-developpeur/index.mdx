Le package **`@suitenumerique/slash-sources-sdk`** permet à n'importe quelle équipe ministérielle ou opérateur public de brancher une nouvelle **Source de Données Souveraine** dans **La Suite Docs** en moins de **15 minutes**.

## 📦 1. Installation du SDK

```bash
pnpm add @suitenumerique/slash-sources-sdk
# ou via npm
npm install @suitenumerique/slash-sources-sdk
```

## ⚡ 2. Création d'un Provider avec `defineSourceProvider`

```typescript
import { defineSourceProvider } from '@suitenumerique/slash-sources-sdk';

export const cadastreProvider = defineSourceProvider({
  type: 'custom',
  name: 'Cadastre & Parcelles (DGFiP)',
  iconName: 'map',
  slashCommand: 'parcelle',
  slashAliases: ['cadastre', 'dgfip', 'section', 'terrain'],
  description: 'Insérer une parcelle cadastrale certifiée DGFiP',

  suggest: async (query, limit = 5) => {
    const res = await fetch(
      `https://apicadastre.data.gouv.fr/suggest?q=${encodeURIComponent(query)}&limit=${limit}`,
    );
    const data = await res.json();
    return data.map((item: any) => ({
      id: item.id,
      title: `Parcelle ${item.section} n°${item.numero}`,
      subtitle: `${item.commune} (${item.code_insee})`,
      type: 'custom',
    }));
  },

  search: async (query, limit = 10) => {
    const res = await fetch(
      `https://apicadastre.data.gouv.fr/search?q=${encodeURIComponent(query)}&limit=${limit}`,
    );
    const data = await res.json();
    return data.map((item: any) => ({
      entityType: 'custom',
      displayMode: 'card',
      sourceId: item.id,
      title: `Parcelle ${item.section} n°${item.numero}`,
      subtitle: `${item.commune} (${item.code_insee})`,
      status: 'Certifié DGFiP',
      statusColor: 'green',
      meta1: `Contenance : ${item.contenance} m²`,
      meta2: `Feuille : ${item.feuille}`,
      meta3: `Mise à jour : ${item.date_maj}`,
      summary: `Parcelle située à ${item.adresse}. Surface cadastrale officielle.`,
      url: `https://cadastre.data.gouv.fr/map?parcelle=${item.id}`,
      verifiedAt: new Date().toLocaleDateString('fr-FR'),
    }));
  },

  getDetail: async (sourceId) => {
    const res = await fetch(`https://apicadastre.data.gouv.fr/parcelles/${sourceId}`);
    return res.json();
  },
});
```

## 🎨 3. Contrat Visuel & Polymorphisme Cunningham

Chaque connecteur bénéficie instantanément des **3 formats de rendu officiels** sans avoir à écrire la moindre ligne de CSS :

1. **📢 Encadré (Callout) :** Bordure gauche Marianne (`var(--c--globals--colors--brand-primary)`), extrait textuel in extenso, badge de statut et lien vers la source.
2. **🗂️ Carte (Card) :** Carte 3 colonnes de métadonnées avec icône thématique et résumé.
3. **🔗 Lien (Link) :** Pastille inline cliquable dans la phrase avec mini-popover de détail au survol.

---

## 🛡️ 4. Bonnes Pratiques & Sécurité

- 🔒 **Zéro Secret Côté Client :** Si votre API requiert un jeton ou un certificat client TLS, implémentez un connecteur backend Django (`core/sources/providers/`) et n'exposez au frontend que les données publiques certifiées.
- ♿ **Accessibilité Native :** Les composants générés par le SDK gèrent automatiquement la navigation au clavier (`↑`, `↓`, `Entrée`, `Échap`) et les attributs ARIA (`combobox`, `listbox`, `aria-expanded`).
