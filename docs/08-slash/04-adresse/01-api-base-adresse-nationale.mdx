L'**API Adresse** est le service national officiel de géocodage et d'autocomplétion des adresses françaises. Co-pilotée par la **DINUM (Etalab)**, l'**ANCT** et l'**IGN**, elle est **100% ouverte, gratuite, souveraine et accessible sans clé d'API obligatoire**.

---

## 📡 1. Endpoints Principaux de l'API Adresse

- **URL de Base :** `https://api-adresse.data.gouv.fr`
- **Format d'Échange :** GeoJSON standard (RFC 7946)
- **Authentification :** Aucune clé requise (service public ouvert)

### Tableau des Endpoints

| Endpoint | Méthode | Usage Principal | Temps de Réponse |
| :--- | :--- | :--- | :--- |
| **`/search/`** | `GET` | Géocodage direct et autocomplétion par texte | ~30 à 60 ms |
| **`/reverse/`** | `GET` | Géocodage inverse (retrouver l'adresse à partir de coordonnées GPS) | ~40 ms |
| **`/search/csv/`** | `POST` | Géocodage en masse de fichiers de données tabulaires | Batch |

---

## 🔍 2. Requête d'Autocomplétion & Paramètres (`/search/`)

### Exemple de Requête HTTP

```http
GET https://api-adresse.data.gouv.fr/search/?q=20+avenue+de+segur+paris&limit=5&autocomplete=1
Accept: application/json
```

### Paramètres Utiles

- **`q`** *(string, obligatoire)* : Texte saisi par l'agent dans l'éditeur (ex: *« 20 avenue de segur »*).
- **`limit`** *(entier, défaut 5)* : Nombre maximal de suggestions retournées.
- **`autocomplete`** *(0 ou 1, défaut 1)* : Active le mode autocomplétion rapide (recherche préfixée et tolérance aux fautes).
- **`type`** *(string, optionnel)* : Filtre par type d'entité : `housenumber` (numéro avec voie), `street` (voie seule), `locality` (lieu-dit), `municipality` (commune).
- **`postcode`** *(string, optionnel)* : Filtre sur un code postal précis (ex: `75007`).
- **`citycode`** *(string, optionnel)* : Filtre sur un code commune INSEE (ex: `75107`).

## 🐍 4. Normalisation vers le Socle Commun (`AddressSourceProvider`)

Le provider Django `AddressSourceProvider` extrait ces données et les mappe vers l'interface `SourceSearchResult` :

```python
results.append({
    "source_id": props.get("id", ""),
    "source_type": "address",
    "provider": "Base Adresse Nationale",
    "title": props.get("label", ""),
    "subtitle": f"Code Postal : {props.get('postcode', '')} — Commune : {props.get('city', '')}",
    "status": "CERTIFIÉE BAN",
    "status_badge_color": "info",
    "contentHtml": f"<p><strong>Adresse officielle :</strong> {props.get('label', '')}</p><p>Coordonnées GPS : {coords[1]}, {coords[0]}</p>",
    "summary": f"Adresse certifiée par la mairie ({props.get('city', '')}).",
    "meta_field_1_label": "Code INSEE",
    "meta_field_1_value": props.get("citycode", ""),
    "meta_field_2_label": "Type",
    "meta_field_2_value": "Numéro et voie" if props.get("type") == "housenumber" else "Voie",
    "meta_field_3_label": "Score",
    "meta_field_3_value": f"{round(props.get('score', 0) * 100)}%",
    "url": f"https://adresse.data.gouv.fr/base-adresse-nationale/{props.get('id', '')}",
})
```
