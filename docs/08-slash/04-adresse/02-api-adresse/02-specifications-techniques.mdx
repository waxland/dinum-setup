L'API Adresse officielle d'Etalab / IGN expose des endpoints performants au format standard **GeoJSON**.

---

## 📡 1. Endpoints Principaux

| Endpoint | Méthode | Rôle | Paramètres Clés |
| :--- | :--- | :--- | :--- |
| **`/search/`** | `GET` | Autocomplétion et géocodage texte | `q`, `limit`, `autocomplete`, `type`, `postcode`, `citycode` |
| **`/reverse/`** | `GET` | Géocodage inverse (coordonnées GPS $\rightarrow$ adresse) | `lat`, `lon`, `type` |

---
