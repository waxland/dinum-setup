La commande **`/adresse`** (alias **`/ban`**, **`/address`**, **`/geo`**, **`/rue`**) permet aux agents territoriaux, secrétaires de mairie, instructeurs d'urbanisme et rédacteurs administratifs de rechercher et d'insérer des adresses postales certifiées par la **Base Adresse Nationale (BAN)** dans **La Suite Docs**.

Ce dossier structure l'ensemble de la démarche en **trois pôles normés** : le cadre légal territorial (loi 3DS), la veille sur les APIs de géocodage et le raccordement au socle commun.

## 🧩 Formats d'Affichage Disponibles

Conformément au **[Socle Technique Unifié](/08-slash/00-socle-technique)** :
- 📢 **Format Callout** : Adresse complète certifiée BAN avec lien vers la fiche nationale.
- 🗂️ **Format Carte** : Encart avec grille : Code INSEE • Type • Coordonnées GPS.
- 🔗 **Format Lien** : Mention compacte `📍 20 Avenue de Ségur, 75007 Paris`.
