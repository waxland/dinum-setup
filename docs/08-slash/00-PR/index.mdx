## 📊 Matrice d'Évaluation Comparative pour la DINUM

| Critère d'Arbitrage | Typologie 1 : PR Interne In-Tree | Typologie 2 : PR Externe Packagée | Analyse & Impact DINUM |
| :--- | :--- | :--- | :--- |
| **Empreinte sur `suitenumerique/docs`** | **+45 fichiers** créés directement dans le cœur | **0 nouveau fichier métier**, **~10 lignes** modifiées | 🟢 **Avantage Typologie 2** (PR quasi-invisible pour les mainteneurs) |
| **Effort de Revue de Code (PR Review)** | Élevé (~1 800 lignes à relire par les mainteneurs de Docs) | Faible (10 lignes de câblage standard) | 🟢 **Avantage Typologie 2** (Acceptation accélérée) |
| **Gouvernance & Acceptation Upstream** | Risque de rejet (spécificités franco-françaises dans un commun international) | **Acceptation garantie** (activation 100% opt-in et découplée) | 🟢 **Avantage Typologie 2** |
| **Cycle de Vie & Maintenance des APIs** | Toute mise à jour d'un connecteur nécessite une release globale de Docs | Release indépendante des packages npm/PyPI en quelques minutes | 🟢 **Avantage Typologie 2** (Agilité maximale) |
| **Réutilisabilité Transverse Interministérielle** | Nulle (le code est captif de `apps/impress`) | **Universelle** (utilisable par *Projects*, *Meet*, *People*, portails tiers) | 🟢 **Avantage Typologie 2** (Mutualisation des deniers publics) |
| **Complexité de Release Initiale** | Nulle (pas de publication sur registre externe) | Nécessite la configuration de pipelines npm & PyPI | 🟡 **Léger avantage Typologie 1 au démarrage** (déjà résolu par la CI/CD configurée) |

## 🎯 Recommandation Stratégique

La **Typologie 2 (PR Externe Packagée)** est la recommandation d'ingénierie officielle pour la DINUM :
1. Elle préserve l'intégrité et la vocation internationale du dépôt open source `suitenumerique/docs`.
2. Elle permet une mise à jour continue des connecteurs administratifs français sans impacter les cycles de version de l'application documentaire.
3. Elle maximise l'impact des investissements de l'État en mettant à disposition de tous les ministères des briques réutilisables certifiées.
