La **Typologie 2** conditionne le socle souverain sous la forme de **packages indépendants et réutilisables** (`django-lasuite-sources` et `@suitenumerique/blocknote-sources`).

La Pull Request soumise sur le dépôt officiel [`suitenumerique/docs`](https://github.com/suitenumerique/docs) est **ultra-légère et non-intrusive** : elle se résume à l'installation des dépendances et à leur enregistrement en **moins de 10 lignes de code**.

## 📝 2. Diff Exhaustif de la PR sur `suitenumerique/docs` (< 10 Lignes)

Voici l'intégralité du diff Git à soumettre dans la Pull Request pour activer le socle souverain dans La Suite Docs :

#### 1. Dépendance Python (`pyproject.toml` ou `requirements.txt`)

## 🚀 3. Avantages Stratégiques & Bénéfices Opérationnels

| Dimension | Bénéfice Direct pour la DINUM |
| :--- | :--- |
| **🟢 Friction Zéro pour les Mainteneurs** | Les mainteneurs de `suitenumerique/docs` n'ont qu'à valider **10 lignes de configuration standard** au lieu d'auditer 45 fichiers spécifiques aux administrations françaises. |
| **🟢 Résilience & Découplage de Release** | Si une API ministérielle (ex: DILA, BAN, BOAMP) modifie son contrat de données, le correctif est publié sur PyPI/npm en **< 15 minutes** sans bloquer le calendrier de release de La Suite Docs. |
| **🟢 Mutualisation Multi-Produits** | Le même connecteur `django-lasuite-sources` peut être installé instantanément dans **La Suite Projects**, **La Suite People**, **La Suite Meet** ou n'importe quel portail ministériel tiers. |
| **🟢 Gouvernance Open Source Propre** | Les organisations étrangères ou européennes utilisant La Suite Docs ne sont pas alourdies par des modules nationaux dont elles n'ont pas l'usage. |
| **🟢 Respect Intransigeant des Standards** | Les packages intègrent nativement les règles du skill `code-standards` (0 any, 0 cast, 0 Mantine UI, 0 Tailwind, RGAA AA). |
