---

## 🎨 1. Déclinaison dans les 3 Formats DSFR

1. 📢 **Format Callout (Fiche de Banc)** : Encart complet avec dispositif juridique, avis du gouvernement et sort du vote.
2. 🗂️ **Format Carte (Synthèse Amendement)** : Grille responsive Groupe • Auteur • Sort.
3. 🔗 **Format Lien (Inline Badge)** : `🏛️ Amdt n° 142 (Art. 4) — ADOPTÉ`.

---

## ⚙️ 2. Configuration d'Environnement

```dotenv
# .env.local ou common.local

# URL de l'API parlementaire (claire.vite ou Tricoteuse locale)
CLAIRE_VITE_API_URL=https://api.claire.vite/v1

# Ou instance Tricoteuse auto-hébergée
# TRICOTEUSE_API_URL=http://tricoteuse-service:8000

# Mode Mock pour tests locaux sans connexion
PARLIAMENT_MOCK_ENABLED=false
```
