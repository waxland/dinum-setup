L'API Pappers centralise les informations légales des entreprises dans des schémas JSON standardisés.

---

## 📡 1. Endpoints Principaux

| Endpoint | Méthode | Rôle | Paramètres Clés |
| :--- | :--- | :--- | :--- |
| **`/v2/recherche`** | `GET` | Recherche par dénomination, mot-clé ou SIREN | `q`, `par_page`, `code_postal` |
| **`/v2/entreprise`** | `GET` | Fiche complète détaillée | `siren` (9 chiffres) |
| **`/v2/suggestions`** | `GET` | Autocomplétion ultra-rapide | `q`, `cibles` |

---
