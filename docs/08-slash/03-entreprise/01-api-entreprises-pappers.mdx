L'API **Pappers Entreprises** agrège les bases publiques officielles (INSEE / SIRENE, INPI / RNE, BODACC, Greffes des Tribunaux de Commerce) en une API REST unifiée et haute performance.

---

## 🔑 1. Authentification & Endpoints

L'authentification s'effectue via un jeton secret transmis en header ou paramètre :

- **Base URL :** `https://api.pappers.fr/v2`
- **Header :** `X-API-Key: <VOTRE_API_KEY_PAPPERS>`

### Endpoints Principaux

| Endpoint | Méthode | Usage |
| :--- | :--- | :--- |
| **`/recherche`** | `GET` | Recherche textuelle par dénomination, mot-clé, ville ou code postal |
| **`/entreprise`** | `GET` | Fiche complète d'une entreprise via son numéro SIREN (9 chiffres) |
| **`/suggestions`** | `GET` | Autocomplétion ultra-rapide pour le champ de recherche |
| **`/document/telechargement`** | `GET` | Téléchargement des statuts ou extrait Kbis |

## 🧪 3. Mode Mock pour le Développement Local

Pour permettre à n'importe quel développeur ou contributeur de tester la commande `/pappers` sans souscrire de clé API commerciale payante, le backend Django intègre un **mode Mock activable par variable d'environnement** :

```dotenv
# .env.local ou common.local
PAPPERS_MOCK_ENABLED=true
```

Lorsque ce mode est activé :
- Les recherches retournent des fixtures d'entreprises réalistes pré-enregistrées (SASU d'ingénierie, ETI industrielle, entreprise en redressement pour tester les alertes).
- Aucun appel réseau sortant n'est émis vers l'extérieur.
- Les tests automatisés et scénarios E2E Playwright s'exécutent sans latence ni dépendance réseau.

## 🏛️ 4. Alternative Souveraine : API Entreprise (DINUM)

Pour les déploiements officiels en production au sein des ministères et collectivités, la commande `/pappers` peut être basculée sur l'**API Entreprise** opérée par la DINUM :

- **Accès réservé aux administrations :** Gratuit pour les personnes morales de droit public habilitées.
- **Données certifiées de l'État :** Flux directs DGFiP (liasses fiscales), Urssaf (attestations de vigilance), Infogreffe et RNE.
- **Principe « Dites-le-nous une fois » :** Dispense les entreprises candidates aux marchés publics de fournir leurs bilans et extraits Kbis.
