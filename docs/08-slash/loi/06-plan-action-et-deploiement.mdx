## 🧪 3. Stratégie de Tests Automatisés E2E Playwright

Le test valide l'ensemble du cycle : déclenchement, sélection, bascule de mode et réplication temps réel :

```typescript
import { test, expect } from "@playwright/test";

test.describe("Fonctionnalité Commande Slash /loi & Modes d'Affichage", () => {
  test("Insertion et bascule entre Extrait, Référence et Lien", async ({
    page,
    context,
  }) => {
    // 1. Ouvrir l'éditeur collaboratif
    await page.goto("http://localhost:3000/doc/test-loi");
    await page.locator(".bn-editor").click();

    // 2. Déclencher la commande slash
    await page.keyboard.type("/loi");

    // 3. Vérifier l'ouverture du menu contextuel compact (max 380px)
    const popup = page.locator("[data-law-popup]");
    await expect(popup).toBeVisible();
    await page.locator("input[placeholder*='Sujet, article']").fill("1240");
    await page.keyboard.press("Enter");

    // 4. Vérifier l'insertion en mode Extrait par défaut
    const extraitBlock = page.locator("[data-law-article='LEGIARTI000032041571']");
    await expect(extraitBlock).toBeVisible();
    await expect(extraitBlock).toContainText("Article 1240 · Code civil");

    // 5. Basculer en mode Référence
    await page.locator("button:has-text('Extrait ▾')").click();
    await page.locator("button:has-text('Référence')").click();
    await expect(page.locator(".h-\\[52px\\]")).toBeVisible();

    // 6. Basculer en mode Lien
    await page.locator("button:has-text('Référence ▾')").click();
    await page.locator("button:has-text('Lien')").click();
    const inlineLink = page.locator("button:has-text('Article 1240 du Code civil')");
    await expect(inlineLink).toBeVisible();

    // 7. Clic sur le lien pour ouvrir la barre contextuelle
    await inlineLink.click();
    await expect(page.locator("a:has-text('Légifrance ↗')")).toBeVisible();
  });
});
```

## 🛡️ 4. Matrice des Risques & Mesures de Mitigation

| Risque Identifié | Probabilité | Impact | Stratégie de Mitigation |
| :--- | :--- | :--- | :--- |
| **Indisponibilité temporaire de l'API PISTE** | Moyenne | Élevé | Cache Redis 24h + base locale embarquée des 500 articles les plus cités en repli. |
| **Changement de version de BlockNote** | Faible | Moyen | Utilisation exclusive des APIs publiques `createReactBlockSpec` sans forker le core. |
| **Désynchronisation lors de grosses modifications** | Faible | Élevé | Propriétés atomiques immuables dans le CRDT Yjs ; interdiction de modifier le texte légal à la main. |
| **Régression d'accessibilité (RGAA)** | Faible | Élevé | Intégration d'un audit automatisé `axe-core` dans la pipeline CI GitHub Actions. |
