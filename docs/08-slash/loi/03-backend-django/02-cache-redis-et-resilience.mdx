L'interconnexion avec une API externe d'État requiert une stratégie de tolérance aux pannes pour garantir que l'éditeur Docs ne subit aucun ralentissement.

---

## ⚡ 1. Stratégie de Cache Redis à Deux Niveaux

    Req["Requête de recherche /loi"] --> CheckCache{"Clé présente dans Redis ?"}

    Fallback -->|Oui| ReturnStale["Renvoi des données périmées (Stale)"]

## 🛡️ 2. Gestion des Pannes Réseau (Circuit Breaker)

Si l'API PISTE subit un incident technique ou une coupure réseau :

1. **Timeout strict :** Tous les appels HTTP backend vers PISTE sont limités à un timeout maximal de **3,5 secondes**.
2. **Dégradation gracieuse :** Si l'API ne répond pas, le backend renvoie un code `200` avec un avertissement `"service_status": "degraded"`.
3. **Zéro blocage de l'éditeur :** L'agent public peut continuer à écrire, modifier et collaborer sur son document sans interruption.

---

## 📈 3. Rate Limiting Utilisateur

Pour éviter qu'un utilisateur ou un bot n'épuise le quota global de l'organisation sur PISTE :

```python
# settings.py
REST_FRAMEWORK = {
    'DEFAULT_THROTTLE_CLASSES': [
        'rest_framework.throttling.UserRateThrottle',
    ],
    'DEFAULT_THROTTLE_RATES': {
        'user': '60/minute',
        'laws_search': '30/minute',
    }
}
```
