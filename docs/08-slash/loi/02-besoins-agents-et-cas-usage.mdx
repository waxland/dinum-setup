La rédaction administrative au sein de l'État et des collectivités locales ne ressemble à aucun autre secteur : **le droit n'y est pas un accessoire, il est la matière première de chaque décision**.

Ce chapitre détaille les freins actuels vécus par les agents publics et met en lumière les cas d'usage emblématiques où la commande `/loi` apporte un saut qualitatif majeur.

---

## 🛑 1. Le Diagnostic : Les Limites du Copier-Coller Manuel

Aujourd'hui, lorsqu'un agent doit inclure un article de loi dans un document partagé, son parcours ressemble à ceci :

<Mermaid chart={`flowchart LR
    A["1. Recherche Google<br/><i>'article marchés sans pub'</i>"] --> B["2. Clic sur un lien tiers<br/><i>(Blog juridique, forum, vieux PDF)</i>"]
    B --> C["3. Copier-coller du texte brut<br/><i>(Formatage cassé, sauts de lignes)</i>"]
    C --> D["4. Absence de lien de source<br/><i>(Texte statique sans métadonnée)</i>"]
    D --> E["❌ Risque élevé :<br/><b>Article abrogé, modifié ou erroné !</b>"]
`} />

### Les 4 Risques Majeurs Identifiés sur le Terrain

1. **L'Obsolescence Silencieuse :** Un projet de note ou un marché public peut prendre 3 à 6 mois de rédaction collaborative. Durant ce laps de temps, une loi de finances ou un décret peut modifier les articles cités. Dans un document texte classique, rien n'alerte les auteurs de cette modification.
2. **La Rupture de Traçabilité :** Le texte collé ne conserve aucun lien officiel vers Légifrance. Un relecteur ou un supérieur hiérarchique est contraint de rouvrir son navigateur pour vérifier l'exactitude de l'extrait.
3. **La Pollution Visuelle & l'Inaccessibilité :** Les extraits collés introduisent des polices disparates, des indentations non conformes et cassent la structure sémantique du document, dégradant la conformité **RGAA**.
4. **La Surcharge Cognitive :** Les agents passent un temps considérable à naviguer entre des dizaines d'onglets au lieu de se concentrer sur l'analyse de fond.

## 🎯 3. Cas d'Usage Concrets dans La Suite Docs

### Cas n°1 : Rédaction d'un Marché Public pour l'achat de serveurs

Un acheteur du Ministère de l'Économie prépare le rapport de présentation d'un marché passé sans publicité ni mise en concurrence préalables pour cause d'urgence impérieuse.

```
Agent : Tape "/loi" dans l'éditeur
Docs : Affiche la modal de recherche Légifrance
Agent : Sélectionne "Code de la commande publique", tape "L. 2122-1"
Docs : Insère instantanément le bloc certifié officiel avec lien LEGIARTI
```

**Bénéfice :** Aucun doute possible pour le contrôle de légalité ou la Cour des comptes : le texte de l'article et son statut « En vigueur » sont scellés et vérifiables en 1 clic.

---

### Cas n°2 : Arrêté Municipal Temporaire de Stationnement

Un agent de police municipale rédige un arrêté interdisant le stationnement lors d'une fête locale. Tout arrêté doit obligatoirement comporter les **« Visas »** (ex: _« Vu le Code général des collectivités territoriales, notamment ses articles L. 2212-1 et L. 2213-2... »_).

```
Agent : Crée la section "Visas"
Agent : Utilise "/loi" pour insérer les articles du CGCT encadrant les pouvoirs de police du maire
Docs : Intègre les articles avec le formatage officiel DSFR
```

**Bénéfice :** Gain de temps de 15 minutes par arrêté, élimination des coquilles sur les numéros d'articles et conformité totale avec le modèle réglementaire.

---

### Cas n°3 : Note de Cadrage sur le Dépôt Légal des Codes Sources

Une équipe de La Suite numérique rédige une note pour expliciter l'obligation d'ouverture des codes sources publics en vertu du **Code des relations entre le public et l'administration (CRPA)**.

```
Agent : Tape "/loi" -> Code des relations entre le public et l'administration -> Article L. 300-2
Docs : Insère la définition des documents administratifs communicables (incluant les codes sources)
```

**Bénéfice :** Les collaborateurs et partenaires qui consultent la note ont accès au texte législatif brut directement sans quitter La Suite Docs.

## 📊 4. Matrice Comparative : Avant vs Après `/loi`

| Critère d'Évaluation | Approche Manuelle Historique | Avec la Commande `/loi` dans Docs |
| :--- | :--- | :--- |
| **Temps moyen d'insertion** | 2 à 4 minutes par article | **Moins de 5 secondes** |
| **Authenticité des données** | Aléatoire (blogs, PDF non datés) | **100% Certifiée (API officielle DILA)** |
| **Pérennité & Métadonnées** | Aucune métadonnée (texte mort) | **Identifiants LEGIARTI & URL pérenne** |
| **Détection d'abrogation** | Nulle (risque contentieux) | **Alerte visuelle si l'article est modifié** |
| **Conformité Accessibilité** | Souvent non conforme RGAA | **Conforme RGAA v4.1 Niveau AA (DSFR)** |
| **Édition Collaborative** | Risque d'écrasement ou décalage | **Synchronisation temps réel native Yjs CRDT** |
