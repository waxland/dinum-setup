L'API Légifrance officielle est hébergée sur la plateforme gouvernementale **PISTE** (_Plateforme d'Intermédiation des Services pour la Transformation de l'État_) opérée par la DILA.

## 🔐 1. Flux OAuth2 Client Credentials

L'API utilise le flux standard **OAuth2 Client Credentials (RFC 6749)**. L'application backend La Suite Docs s'authentifie directement auprès du serveur d'autorisation PISTE sans intervention de l'utilisateur final.

## 📡 2. Endpoints d'Authentification

### URL du serveur de jetons (Token Endpoint)
- **Environnement Production :** `https://oauth.piste.gouv.fr/api/oauth/token`
- **Environnement Sandbox / Recette :** `https://sandbox-oauth.piste.gouv.fr/api/oauth/token`

### Requête de demande de jeton (cURL)

```bash
curl --request POST \
  --url 'https://oauth.piste.gouv.fr/api/oauth/token' \
  --header 'Content-Type: application/x-www-form-urlencoded' \
  --data 'grant_type=client_credentials' \
  --data 'client_id=VOTRE_CLIENT_ID_PISTE' \
  --data 'client_secret=VOTRE_CLIENT_SECRET_PISTE' \
  --data 'scope=openid'
```

### Exemple de réponse JSON

```json
{
  "access_token": "eyJhbGciOiJSUzI1NiIs...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "openid"
}
```

## ⚡ 3. Quotas, Rate Limiting & Bonnes Pratiques

| Paramètre | Limite standard PISTE | Stratégie La Suite Docs |
| :--- | :--- | :--- |
| **Quota d'appels** | 100 req/min par Client ID | Cache Redis local avec TTL 24h sur les requêtes `/search` |
| **Expiration Token** | 3600 secondes (1 heure) | Renouvellement automatique anticipé à 3500 secondes |
| **Failover / Mode Dégradé** | Erreur HTTP 429 (Too Many Requests) | Retour des résultats en cache ou message explicite sans bloquer l'éditeur |
