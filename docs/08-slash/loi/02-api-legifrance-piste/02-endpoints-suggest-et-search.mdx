L'API Légifrance expose trois endpoints principaux permettant de construire une expérience de recherche fluide dans un éditeur de texte.

---

## 🧭 1. Rôle des Trois Endpoints

| Endpoint | Méthode | Rôle principal | Temps de réponse moyen |
| :--- | :--- | :--- | :--- |
| **`/suggest`** | `POST` | Autocomplétion ultra-rapide pendant la saisie | ~80 ms |
| **`/search`** | `POST` | Recherche structurée multi-critères avec filtres juridiques | ~250 ms |
| **`/consult/...`** | `POST` | Récupération du texte intégral et de la structure d'un article | ~150 ms |

---

## ⚡ 2. Endpoint `/suggest` (Autocomplétion)

### Requête

```http
POST https://api.piste.gouv.fr/dila/legifrance/lf-engine-app/suggest
Authorization: Bearer <ACCESS_TOKEN>
Content-Type: application/json
Accept: application/json

{
  "searchText": "pouvoir du prefet",
  "supplies": ["ALL_SUGGEST"]
}
```

### Paramètres clés

- **`searchText`** *(string, obligatoire)* : Termes saisis par l'utilisateur dans l'interface de recherche.
- **`supplies`** *(array de strings)* : Fonds documentaires ciblés (`ALL_SUGGEST`, `CODE_LIST`, `JORF_SUGGEST`, etc.).

## 🔍 3. Endpoint `/search` (Recherche Structurée)

### Requête

```http
POST https://api.piste.gouv.fr/dila/legifrance/lf-engine-app/search
Authorization: Bearer <ACCESS_TOKEN>
Content-Type: application/json
Accept: application/json

{
  "fond": "LODA_DATE",
  "recherche": {
    "champs": [
      {
        "typeChamp": "ALL",
        "criteres": [
          {
            "typeRecherche": "TOUS_LES_MOTS_DANS_UN_CHAMP",
            "valeur": "secret professionnel agent public",
            "operateur": "ET"
          }
        ],
        "operateur": "ET"
      }
    ],
    "filtres": [],
    "pageNumber": 1,
    "pageSize": 10,
    "operateur": "ET",
    "sort": "PERTINENCE",
    "typePagination": "DEFAUT"
  }
}
```

## 📖 4. Endpoint `/consult/getArticle` (Consultation Intégrale)

Cet endpoint permet d'obtenir le texte d'un article précis à partir de son identifiant unique (`id` ou `cid`).

### Requête

```http
POST https://api.piste.gouv.fr/dila/legifrance/lf-engine-app/consult/getArticle
Authorization: Bearer <ACCESS_TOKEN>
Content-Type: application/json

{
  "id": "LEGIARTI000038814944"
}
```

### Réponse retournée
- Numéro d'article (ex: `Article L111-1`)
- Texte brut et formaté HTML
- Date d'entrée en vigueur
- État juridique (`VIGUEUR`, `ABROGE`)
- Titre du code ou de la loi de rattachement
