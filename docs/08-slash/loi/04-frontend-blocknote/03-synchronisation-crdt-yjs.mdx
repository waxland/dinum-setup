## 📦 2. Structure JSON Sérialisée dans Yjs

Lorsqu'un bloc de loi est créé, BlockNote le sérialise dans le fragment XML partagé sous forme d'objet structuré :

```json
{
  "id": "block-law-9821a",
  "type": "lawArticle",
  "props": {
    "articleId": "LEGIARTI000038814944",
    "articleNum": "Article L. 111-1",
    "codeTitle": "Code de la commande publique",
    "status": "VIGUEUR",
    "displayMode": "citation",
    "url": "https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000038814944",
    "contentHtml": "Un acheteur ou une autorité concédante est un pouvoir adjudicateur..."
  },
  "content": []
}
```

Cette structure garantit :
1. **L'indépendance réseau :** Même hors-ligne ou si PISTE est inaccessible, les coauteurs peuvent lire et modifier le document avec le texte conservé dans l'arbre Yjs.
2. **L'intégrité collaborative :** Les modifications du mode d'affichage (`displayMode`) sont propagées instantanément à tous les participants.
