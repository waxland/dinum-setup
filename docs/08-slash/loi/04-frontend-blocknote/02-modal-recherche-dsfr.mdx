Lorsqu'un agent tape `/loi` et appuie sur Entrée, une modale de recherche s'ouvre pour permettre la sélection précise du texte ou de l'article à insérer.

---

## ♿ 1. Exigences d'Accessibilité (RGAA v4.1 Niveau AA)

1. **Piégeage du focus clavier :** Le focus reste confiné à l'intérieur de la modale tant qu'elle est ouverte (`Tab` / `Shift+Tab`).
2. **Touche Échap (`Escape`) :** Ferme immédiatement la modale et replace le curseur à l'endroit exact de la saisie.
3. **Lecteurs d'écran (ARIA) :** Utilisation des attributs `role="dialog"`, `aria-modal="true"`, et `aria-labelledby`.
4. **Gestion de l'autocomplétion :** Annonce vocale dynamique (`aria-live="polite"`) du nombre de résultats trouvés.

## ⌨️ 3. Enregistrement de la Commande Slash dans BlockNote

```tsx
import { BlockNoteEditor } from "@blocknote/core";

export function getLawSlashMenuItem(editor: BlockNoteEditor, openModal: () => void) {
  return {
    name: "Texte de Loi (Légifrance)",
    execute: () => {
      openModal();
    },
    aliases: ["loi", "law", "legifrance", "article", "code", "decret"],
    group: "Sources Officielles",
    icon: <span>⚖️</span>,
    hint: "Insérer un article de loi certifié depuis Légifrance",
  };
}
```
