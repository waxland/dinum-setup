## ⏱️ 2. Objectifs RTO / RPO

| Métrique                             | Valeur Cible   | Description                                                                                                    |
| ------------------------------------ | -------------- | -------------------------------------------------------------------------------------------------------------- |
| **RPO (_Recovery Point Objective_)** | $< 1$ minute   | Perte maximale de données admissible en cas de sinistre majeur (grâce à l'archivage continu des segments WAL). |
| **RTO (_Recovery Time Objective_)**  | $< 30$ minutes | Temps maximal pour restaurer l'ensemble des services opérationnels sur une nouvelle infrastructure.            |

---

## 🔄 3. Procédure de Restauration Point-in-Time (PITR)

Pour restaurer une base de données à un instant précis (par exemple, juste avant une corruption accidentelle survenue à `2026-04-12 14:32:00 UTC`) :

```bash
# 1. Récupérer le backup complet le plus proche
wal-g backup-fetch /var/lib/postgresql/data LATEST

# 2. Configurer la cible de restauration dans postgresql.conf
cat <<EOF >> /var/lib/postgresql/data/postgresql.conf
restore_command = 'wal-g wal-fetch "%f" "%p"'
recovery_target_time = '2026-04-12 14:32:00 UTC'
recovery_target_action = 'promote'
EOF

# 3. Créer le fichier signal de restauration et démarrer le service
touch /var/lib/postgresql/data/recovery.signal
systemctl start postgresql
```
