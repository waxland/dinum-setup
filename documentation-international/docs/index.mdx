**Slasher** (`@suitenumerique/blocknote-sources` / `@blocknote/xl-external-sources`) is an open source community extension and lightweight SDK (`@suitenumerique/slash-sources-sdk` < 5 kB) that connects rich text editors with verified remote public registries, legal databases, and enterprise APIs.

## 🏛️ 3-Tier Architecture

<Mermaid chart={`flowchart TD
    subgraph Editor["📝 Rich Text Editor (React 18 / 19)"]
        SlashCommand["Type '/' or Trigger Shortcut"] --> Popover["Accessible Floating Popover (cmdk + ARIA)"]

    end

    subgraph Core["📦 Decoupled Packages (DINUM & Community)"]
        SDK["🛠️ Provider SDK (@suitenumerique/slash-sources-sdk)"]

    subgraph GlobalData["🌍 Sovereign & Global APIs (53 Connectors)"]
