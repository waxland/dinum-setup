# 🌐 Slasher — Universal Remote Data Connectors for BlockNote

**Slasher** (`@blocknote/xl-external-sources`) is an open source community extension and lightweight SDK (`@blocknote/source-provider-sdk` < 5 kB) that connects rich text editors with remote public and private APIs.

```mermaid
flowchart TD
    subgraph SlasherEcosystem["🌐 Slasher 3-Tier Architecture"]
        Editor["📝 BlockNote.js Editor / React 18 & 19"]
        SlasherBlock["🧩 SlasherBlock (3 Switchable Formats)"]
        Popover["🔍 Floating Search Popover (cmdk + WAI-ARIA)"]
        SDK["🛠️ Slasher SDK (defineSourceProvider)"]
        BackendProxy["🐍 Backend Proxy & Deterministic Redis Cache (SHA-256)"]
        RemoteAPIs["🏛️ Public & Enterprise APIs (EU, France, Germany, Netherlands, Spain)"]
    end

    Editor --> SlasherBlock
    Editor --> Popover
    Popover --> SDK
    SDK --> BackendProxy
    BackendProxy --> RemoteAPIs
```
