The backend layer (`django-lasuite-sources`) acts as a secure, high-performance proxy gateway between client-side rich text editors and upstream sovereign APIs.

<Mermaid
  chart={`flowchart LR
    Editor["Client Editor"] -->|GET /api/v1/sources/suggest/| Proxy["Django REST Proxy"]
    Proxy -->|SHA-256 Key| Cache{"Redis Cache (24h)"}
    Cache -->|Hit| Editor
    Cache -->|Miss| TokenBucket["Redis Lua Token Bucket"]
    TokenBucket -->|Allowed| SSRF["PublicResolver (Anti-SSRF)"]
    TokenBucket -->|Rate Limited (429)| Editor
    SSRF --> Upstream["Upstream Sovereign API"]
    Upstream -->|Normalize DTO| Cache`}
/>
