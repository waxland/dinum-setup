## 💻 Provider Implementation (Django)

Here is a reference implementation of the Canadian federal law connector (`JusticeLawsProvider`), mapping the Canadian Department of Justice's XML/JSON structure into the unified `SourceSearchResult` DTO, using the internal `self._fetch()` wrapper to ensure Anti-SSRF protection.

```python
from django.conf import settings
from ..base import BaseSourceProvider, SourceSearchResult

class JusticeLawsProvider(BaseSourceProvider):
    provider_id = "canlaw"
    source_type = "law"

    # Justice Laws Canada Open Data Endpoint
    API_URL = "https://laws-lois.justice.gc.ca/eng/XML/api/search"

    def is_enabled(self) -> bool:
        return getattr(settings, "ENABLE_CA_PROVIDERS", True)

    def search(self, query: str, limit: int = 5) -> list[SourceSearchResult]:
        headers = {"Accept": "application/json"}
        params = {
            "q": query,
            "limit": limit
        }

        # _fetch() automatically routes through PublicResolver to block SSRF and enforce the 3.5s timeout.
        resp = self._fetch("GET", self.API_URL, params=params, headers=headers)
        resp.raise_for_status()
        data = resp.json().get("results", [])

        results: list[SourceSearchResult] = []
        for item in data:
            results.append({
                "source_id": item.get("id", ""),
                "source_type": "law",
                "provider": "Justice Laws Canada",
                "country": "ca",
                "title": item.get("title", ""),
                "subtitle": f"Act: {item.get('chapter', '')}",
                "status": "In Force" if item.get("inForce") else "Repealed",
                "status_badge_color": "success" if item.get("inForce") else "error",
                "contentHtml": item.get("summaryHtml", ""),
                "url": f"https://laws-lois.justice.gc.ca/eng/acts/{item.get('id', '')}/",
            })
        return results
```

## 🧩 Display Formats

When inserting a Canadian legal act via `/canlaw` or a company via `/corporation-ca`, Slasher dynamically adapts the output to 3 display formats:

- 📢 **Callout**: Full legislative text extraction with an official border color.
- 🗂️ **Card**: 3-column metadata grid displaying Business Number (BN9), incorporation date, and jurisdiction.
- 🔗 **Inline**: A compact, clickable pill embedded in the text flow.
