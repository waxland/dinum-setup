## 💻 Provider Implementation (Django)

The following snippet demonstrates the `BOEProvider`, transforming Spanish official journal data into a consumable block for the editor.

```python
import requests
from django.conf import settings
from ..base import BaseSourceProvider, SourceSearchResult

class BOEProvider(BaseSourceProvider):
    provider_id = "ley"
    source_type = "law"

    # Hypothetical Open Data endpoint for BOE
    API_URL = "https://api.boe.es/search"

    def is_enabled(self) -> bool:
        return getattr(settings, "ENABLE_ES_PROVIDERS", True)

    def search(self, query: str, limit: int = 5) -> list[SourceSearchResult]:
        headers = {"Accept": "application/json"}
        params = {
            "q": query,
            "limit": limit
        }

        resp = requests.get(self.API_URL, params=params, headers=headers, timeout=3.5)
        resp.raise_for_status()
        data = resp.json().get("results", [])

        results: list[SourceSearchResult] = []
        for item in data:
            results.append({
                "source_id": item.get("boe_id", ""),
                "source_type": "law",
                "provider": "Boletín Oficial del Estado",
                "country": "es",
                "title": item.get("title", ""),
                "subtitle": f"Disposición: {item.get('departamento', '')}",
                "status": "Vigente" if item.get("inForce") else "Derogada",
                "status_badge_color": "success" if item.get("inForce") else "error",
                "contentHtml": item.get("textHtml", ""),
                "url": f"https://www.boe.es/buscar/act.php?id={item.get('boe_id', '')}",
            })
        return results
```

## 🧩 Display Formats

All Spanish providers automatically integrate with the editor's core formatting components:

- 📢 **Callout**: Extracts and visually highlights articles from the BOE, including proper attribution to the corresponding Ministry.
- 🗂️ **Card**: Summarizes Registro Mercantil (NIF, corporate name, province) or PLACSP procurement notices in a structured format.
- 🔗 **Inline**: Compact badge formatting for minimal disruption when citing a specific law or cadastral parcel within a document.
