## 💻 Provider Implementation (Django)

Below is an outline of the Dutch Legal connector (`WettenbankProvider`). It queries the KOOP / Overheid.nl registry and formats the results for immediate use in the text editor.

```python
import requests
from django.conf import settings
from ..base import BaseSourceProvider, SourceSearchResult

class WettenbankProvider(BaseSourceProvider):
    provider_id = "wet"
    source_type = "law"

    # Overheid.nl Open Data API endpoint (hypothetical/official mapping)
    API_URL = "https://api.overheid.nl/wetten/search"

    def is_enabled(self) -> bool:
        return getattr(settings, "ENABLE_NL_PROVIDERS", True)

    def search(self, query: str, limit: int = 5) -> list[SourceSearchResult]:
        headers = {"Accept": "application/json"}
        params = {
            "q": query,
            "limit": limit
        }

        resp = requests.get(self.API_URL, params=params, headers=headers, timeout=3.5)
        resp.raise_for_status()
        data = resp.json().get("results", [])

        results: list[SourceSearchResult] = []
        for item in data:
            results.append({
                "source_id": item.get("jci", ""),
                "source_type": "law",
                "provider": "Wettenbank (KOOP)",
                "country": "nl",
                "title": item.get("title", ""),
                "subtitle": f"Regeling: {item.get('regeling', '')}",
                "status": "Geldig" if item.get("inForce") else "Vervallen",
                "status_badge_color": "success" if item.get("inForce") else "error",
                "contentHtml": item.get("textHtml", ""),
                "url": f"https://wetten.overheid.nl/{item.get('regelingId', '')}/",
            })
        return results
```

## 🧩 Display Formats

All Dutch endpoints adhere strictly to the 3 Slasher presentation modes:

- 📢 **Callout**: Extracts full legal texts (e.g., from the Burgerlijk Wetboek) into an institutional container.
- 🗂️ **Card**: Presents KVK corporate registration data (KVK-nummer, RSIN, Legal form) in a dense 3-column summary.
- 🔗 **Inline**: Provides a small mention badge for referencing BAG addresses natively within a document.
