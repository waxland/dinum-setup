## 💻 Provider Implementation (Django)

The EU connectors are implemented by extending the `BaseSourceProvider` in Python. Here is the reference implementation for the `EurlexSourceProvider` resolving EU treaties and regulations, using the internal `self._fetch()` wrapper to ensure Anti-SSRF protection:

```python
from django.conf import settings
from ..base import BaseSourceProvider, SourceSearchResult

class EurlexSourceProvider(BaseSourceProvider):
    provider_id = "eurlex"
    source_type = "law"

    # EU Publications Office CELLAR Endpoint
    API_URL = "https://eur-lex.europa.eu/api/external/search"

    def is_enabled(self) -> bool:
        return getattr(settings, "ENABLE_EU_PROVIDERS", True)

    def search(self, query: str, limit: int = 5) -> list[SourceSearchResult]:
        headers = {"Accept": "application/json"}
        # EUR-Lex specific query formulation
        params = {
            "q": query,
            "limit": limit,
            "language": "en"
        }

        # _fetch() uses the PublicResolver (Anti-SSRF) and strictly limits timeout to 3.5s
        resp = self._fetch("GET", self.API_URL, params=params, headers=headers)
        resp.raise_for_status()
        data = resp.json().get("results", [])

        results: list[SourceSearchResult] = []
        for item in data:
            results.append({
                "source_id": item.get("celex", ""),
                "source_type": "law",
                "provider": "EUR-Lex (EU)",
                "country": "eu",
                "title": item.get("title", ""),
                "subtitle": f"CELEX: {item.get('celex', '')}",
                "status": "In Force" if item.get("inForce") else "Repealed",
                "status_badge_color": "success" if item.get("inForce") else "error",
                "contentHtml": item.get("summaryHtml", ""),
                "url": f"https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:{item.get('celex', '')}",
            })
        return results
```

## 🧩 Display Formats

When an EU legal act is inserted via `/eurlex`, it supports the 3 standard Slasher formats:

- 📢 **Callout**: Ideal for quoting specific GDPR articles or AI Act recitals in full text.
- 🗂️ **Card**: Displays the CELEX number, adoption date, and official journal reference in a 3-column grid.
- 🔗 **Inline**: A compact CELEX badge embedded directly within a paragraph.
