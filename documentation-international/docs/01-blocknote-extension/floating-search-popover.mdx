The Slasher search popover is built with `cmdk` and adheres to the strict **WCAG 2.1 Level AA** and **RGAA v4.1** accessibility standards.

---

## ⌨️ Keyboard Navigation

- **`↑` / `↓` Arrows :** Navigate between suggestions seamlessly without losing cursor focus.
- **`Enter` :** Select and insert the verified entity into the editor.
- **`Escape` :** Dismiss the popover and remove the empty placeholder block.
- **`Tab` :** Cycle through action buttons (Open source, Copy link, Switch format).

---

## ♿ Screen Reader Support
- `role="combobox"` with dynamic `aria-expanded` and `aria-autocomplete="list"`.
- Live `aria-live="polite"` region announcing search results count and loading status.
