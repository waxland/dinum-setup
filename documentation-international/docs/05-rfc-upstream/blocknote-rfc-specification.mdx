## 🎯 Abstract

This RFC proposes standardizing how BlockNote editors interact with remote data sources through:

1. An ultra-lightweight declarative provider definition helper (`defineSourceProvider()`).
2. A unified, WAI-ARIA accessible floating popover with autocomplete.
3. A switchable CustomBlock rendering entities as **Callouts**, **Cards**, or **Inline Mentions**.
4. Built-in vector document exporters for PDF, Word DOCX, and LibreOffice ODF.
