**Slasher** standardizes how rich text documents interact with verified remote public records, legal databases, corporate registers, and AI knowledge bases. It aims to solve the problem of "dead text" by connecting live, verifiable public data directly into collaborative editors.

## 🏛️ Why Slasher? The Paradigm Shift

### Problem vs. Solution

| Feature             | Dead Copy-Paste (Traditional)         | Verified Connected Blocks (Slasher)                                |
| ------------------- | ------------------------------------- | ------------------------------------------------------------------ |
| **Provenance**      | Anonymous text, hard to verify.       | Embedded verified origin, fetched from official registries.        |
| **Integrity**       | Prone to silent alteration.           | Immutable block payload with timestamped `verifiedAt`.             |
| **Export Fidelity** | Plain text only, breaks formatting.   | Native vector exporters (PDF, DOCX, ODT) keeping original styling. |
| **Accessibility**   | Often inaccessible to screen readers. | Full WAI-ARIA compliance, cmdk autocomplete, focus trapping.       |
